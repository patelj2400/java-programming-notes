# Strings -- Special Characters in Java

In Java, **special characters** inside strings are written using **escape sequences** (because some characters have special meaning in code).

Escape sequences start with a **backslash (`\`)**.

---

# Special Characters in Java Strings

| Escape Sequence | Meaning         | Example Output                |
| --------------- | --------------- | ----------------------------- |
| `\n`            | New Line        | Moves text to the next line   |
| `\t`            | Tab Space       | Adds tab space                |
| `\b`            | Backspace       | Deletes previous character    |
| `\r`            | Carriage Return | Moves cursor to start of line |
| `\f`            | Form Feed       | Page break (rarely used)      |
| `\'`            | Single Quote    | Prints `'`                    |
| `\"`            | Double Quote    | Prints `"`                    |
| `\\`            | Backslash       | Prints `\`                    |
| `\f`            | Form feed       | Page break (rarely used)      |

---

# 1\. New Line (`\n`)

Moves the text to the **next line**.

    public class Main {
        public static void main(String[] args) {
            System.out.println("Hello\nWorld");
        }
    }

Output

    Hello
    World

---

# 2. Tab Space (`\t`)

Adds a **tab space** between words.

    System.out.println("Java\tDSA");

Output

    Java DSA

---

# 3. Backspace (`\b`)

Removes the previous character.

    System.out.println("ABC\bD");

Output

    ABD

---

# 4. Carriage Return (`\r`)

Moves cursor to the **start of the line** and overwrites.

    System.out.println("Hello\rJava");

Output

    Javao

Explanation: `"Java"` overwrites `"Hell"`.

---

# 5. Double Quote (`\"`)

Used when you want to print **quotes inside a string**.

    System.out.println("He said \"Hello\"");

Output

    He said "Hello"

---

# 6. Single Quote (`\'`)

    System.out.println("It\'s Java");

Output

    It's Java

---

# 7. Backslash (`\\`)

    System.out.println("C:\\Users\\Jay");

Output

    C:\Users\Jay

---

# Example Combining Multiple Special Characters

    public class Main {
        public static void main(String[] args) {
            System.out.println("Name:\tJay\nCourse:\tDSA\nLanguage:\tJava");
        }
    }

Output

    Name: Jay
    Course: DSA
    Language: Java

---

✅ **Important for DSA Interviews**

Commonly used escape characters:

- `\n`

- `\t`

- `\"`

- `\\`

These appear in **string manipulation problems, file handling, and formatting output**.

---

# Example Program

---

    public class SpecialCharactersExample {
        public static void main(String[] args) {

            System.out.println("Hello\nWorld");
            System.out.println("Java\tProgramming");
            System.out.println("He said \"Java is powerful\"");
            System.out.println("This is backslash: \\");
            System.out.println("I\'m learning Java");
        }
    }

### Output:

    Hello
    World
    Java    Programming
    He said "Java is powerful"
    This is backslash: \
    I'm learning Java

---

## Why Escape Characters Are Needed?

Example ❌ (Error):

    System.out.println("He said "Hello"");

Compiler gets confused.

Correct ✔:

    System.out.println("He said \"Hello\"");

---

## Unicode Characters in Strings

Java supports **Unicode** using `\u` followed by 4 hexadecimal digits.

Example:

    System.out.println("\u0041");

Output:

    A

---

## Summary

- Special characters use **escape sequences**

- Start with `\`

- Used inside double quotes `" "`

- Java fully supports Unicode
