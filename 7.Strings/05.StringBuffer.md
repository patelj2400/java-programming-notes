# StringBuffer in Java

## 1. What is StringBuffer?

**`StringBuffer`** is a class in Java used to create **mutable (modifiable) strings**.\
Unlike `String`, the content of a `StringBuffer` object **can be changed without creating a new object**.

It is part of the **`java.lang`** package.

    StringBuffer sb = new StringBuffer("Hello");
    sb.append(" World");
    System.out.println(sb);

Output:

    Hello World

Here the original string is modified instead of creating a new one.

---

## 2. Why StringBuffer is Used

In Java:

- String → Immutable (cannot change once created)

- StringBuilder → Mutable but not thread-safe

- StringBuffer → Mutable and thread-safe

👉 StringBuffer is mainly used in multithreaded environments.

In Java, **String objects are immutable**.

Example with String:

    String s = "Hello";
    s = s + " World";

Here:

- A **new object** is created in memory.

But with **StringBuffer**:

    StringBuffer sb = new StringBuffer("Hello");
    sb.append(" World");

Here:

- The **same object is modified**.

- More **memory efficient**.

---

## 3. Important Feature

#### Thread Safe (Synchronized)

`StringBuffer` methods are **synchronized**, which means:

- It is **thread-safe**

- Multiple threads can use it safely.

But because of synchronization, it is **slower than StringBuilder**.

| Feature     | StringBuffer              |
| ----------- | ------------------------- |
| Mutable     | ✅ Yes                    |
| Thread-safe | ✅ Yes (Synchronized)     |
| Performance | Slower than StringBuilder |
| Package     | java.lang                 |

    StringBuffer variableName = new StringBuffer("Initial Value");

Example:

## 5\. Constructors of StringBuffer

#### 1. Empty StringBuffer

    StringBuffer sb = new StringBuffer();

Default capacity = **16**

---

#### 2. With Initial String

    StringBuffer sb = new StringBuffer("Hello");

Capacity = **16 + length of string**

---

#### 3. With Capacity

    StringBuffer sb = new StringBuffer(50);

Capacity = **50**

---

## 6. String vs StringBuffer vs StringBuilder

| Feature     | String   | StringBuffer | StringBuilder |
| ----------- | -------- | ------------ | ------------- |
| Mutable     | ❌ No    | ✅ Yes       | ✅ Yes        |
| Thread Safe | ❌ No    | ✅ Yes       | ❌ No         |
| Performance | Slow     | Medium       | Fast          |
| Introduced  | Java 1.0 | Java 1.0     | Java 1.5      |

## 7\. Simple Example

    public class Test {
        public static void main(String[] args) {
            StringBuffer sb = new StringBuffer("Java");

            sb.append(" Programming");
            sb.insert(4, " Core");
            sb.replace(0, 4, "Advanced");

            System.out.println(sb);
        }
    }

Output

    Advanced Core Programming

---

## 8. Memory Behavior

With **String**

    "Hello" → "Hello World" → "Hello World Java"

(New objects created)

With **StringBuffer**

    Same object modified

---

## 9. When to Use StringBuffer

Use **StringBuffer** when:

- String content changes frequently
- **Multiple threads** are accessing it
- You need **thread safety**
- When multiple threads modify the same string

If thread safety is NOT required → Prefer StringBuilder (faster).

---

## 10. Interview Definition

**StringBuffer is a mutable sequence of characters in Java that is synchronized and thread-safe, allowing modification of the same object without creating new ones.**
