## StringBuilder in Java

In Java, **`StringBuilder`** is a class used to create **mutable (modifiable) strings**.

Unlike `String`, where every modification creates a new object,
`StringBuilder` allows you to change the same object --- making it **faster and memory efficient**

It belongs to:

    java.lang.StringBuilder

---

## 1. Why Do We Need StringBuilder?

#### Problem with `String`

    String s = "Hello";
    s = s + " World";

👉 Each concatenation creates a **new object** in memory.\
👉 Slow when used inside loops.

Example (bad practice in DSA):

    String series = "";

    for(int i = 0; i < 26; i++) {
        series += (char)('a' + i);
    }

#### What happens internally?

Every iteration:

- Creates NEW object
- Copies old string
- Appends new character

So:

    a
    ab
    abc
    abcd
    abcde
    ...

Time Complexity:

    1 + 2 + 3 + ... + n
    = n(n+1)/2
    = O(n²)

---

## 2. Solution: StringBuilder

To avoid O(n²):

Use:

    StringBuilder sb = new StringBuilder();

Then:

    sb.append(ch);

Finally:

    System.out.println(sb.toString());

Example:

    StringBuilder sb = new StringBuilder();
    for(int i = 0; i < n; i++){
        sb.append(i); // Modifies same object ✅
    }

#### Why efficient?

- Only ONE object created
- Modifies same object
- No copying
- Time Complexity = O(n)
- More efficient
- Faster for multiple modifications
- Less memory usage

---

## 3. How StringBuilder Works Internally

- Uses a **resizable character array**

- Default capacity = **16**

- When capacity exceeds → it increases automatically\

Formula:

    newCapacity = (oldCapacity \* 2) + 2

---

## 4. Constructors

    StringBuilder sb1 = new StringBuilder(); // capacity 16
    StringBuilder sb2 = new StringBuilder(50); // custom capacity
    StringBuilder sb3 = new StringBuilder("Hello"); // initialized with string

---

## Important Methods (Very Important for DSA)

### 1. append()

    sb.append("Hello");
    sb.append(100);

- Adds data at the end.

---

### 2. insert()

    sb.insert(1, "A");

- Inserts at specific index.

---

### 3. delete()

    sb.delete(1, 3);

- Deletes from start index (inclusive) to end index (exclusive).

---

### 4. deleteCharAt()

    sb.deleteCharAt(2);

- Deletes single character.

---

### 5. reverse() ⭐ (Very Important in DSA)

    sb.reverse();

- Used in palindrome problems.

---

### 6. setCharAt()

    sb.setCharAt(0, 'X');

- Replace character.

---

### 7. toString()

    String finalString = sb.toString();

- Converts `StringBuilder` → `String`.

---

## String vs StringBuilder vs StringBuffer

| Feature      | String      | StringBuilder | StringBuffer   |
| ------------ | ----------- | ------------- | -------------- |
| Mutable      | ❌ No       | ✅ Yes        | ✅ Yes         |
| Thread Safe  | ✅ Yes      | ❌ No         | ✅ Yes         |
| Speed        | Slow        | Fastest       | Slower         |
| Use Case     | Normal text | DSA / Loops   | Multithreading |
| Memory usage | More        | Less          | Less           |

---

## Time Complexity (Important for Interviews)

| Operation | Complexity |
| --------- | ---------- |
| append()  | O(1)       |
| insert()  | O(n)       |
| delete()  | O(n)       |
| reverse() | O(n)       |
| charAt()  | O(1)       |

## Interview Trick Questions

##### Q. Is StringBuilder thread-safe?

No.

##### Q. Why is StringBuilder faster?

Because it doesn't create new objects for modification.

##### Q. Can we compare two StringBuilders using equals()?

No. It compares reference, not content.
