# StringBuffer methods

---

## 1. append()

**Purpose:** Adds data to the **end of the StringBuffer**.

### Syntax

    sb.append(data);

### Example

    StringBuffer sb = new StringBuffer("Hello");

    sb.append(" World");

    System.out.println(sb);

**Output**

    Hello World

---

## 2. insert()

**Purpose:** Inserts data at a **specific index**.

### Syntax

    sb.insert(index, value);

### Example

    StringBuffer sb = new StringBuffer("Hello");

    sb.insert(5, " Java");

    System.out.println(sb);

**Output**

    Hello Java

---

## 3. replace()

**Purpose:** Replaces characters between a **start index and end index**.

### Syntax

    sb.replace(start, end, string);

### Example

    StringBuffer sb = new StringBuffer("Hello World");

    sb.replace(6, 11, "Java");

    System.out.println(sb);

**Output**

    Hello Java

---

## 4. delete()

**Purpose:** Removes characters between **start and end index**.

### Syntax

    sb.delete(start, end);

### Example

    StringBuffer sb = new StringBuffer("Hello World");

    sb.delete(5, 11);

    System.out.println(sb);

**Output**

    Hello

## 5. reverse()

**Purpose:** Reverses the characters in the buffer.

### Syntax

    sb.reverse();

### Example

    StringBuffer sb = new StringBuffer("Hello");

    sb.reverse();

    System.out.println(sb);

**Output**

    olleH

---

## 6. capacity()

**Purpose:** Returns the **current capacity of the buffer**.

    StringBuffer sb = new StringBuffer();

    System.out.println(sb.capacity());

**Output**

    16

Default capacity = **16 characters**

Formula when expanded:

    newCapacity = (oldCapacity \* 2) + 2

---

## 7. length()

**Purpose:** Returns the **number of characters** currently stored.

    StringBuffer sb = new StringBuffer("Hello");

    System.out.println(sb.length());

**Output**

    5

---

## 8. setCharAt()

**Purpose:** Changes a character at a **specific index**.

    StringBuffer sb = new StringBuffer("Hello");

    sb.setCharAt(0, 'Y');

    System.out.println(sb);

**Output**

    Yello

## 9. charAt()

**Purpose:** Returns the character at a given index.

    StringBuffer sb = new StringBuffer("Hello");

    System.out.println(sb.charAt(1));

**Output**

    e

---

## 10. substring()

**Purpose:** Returns a **substring from the buffer**.

    StringBuffer sb = new StringBuffer("Hello World");

    System.out.println(sb.substring(6));

**Output**

    World

---

# Important Summary

| Method      | Purpose                          |
| ----------- | -------------------------------- |
| append()    | Adds text at the end             |
| insert()    | Inserts text at a specific index |
| replace()   | Replaces part of the string      |
| delete()    | Removes characters               |
| reverse()   | Reverses the string              |
| capacity()  | Returns buffer capacity          |
| length()    | Returns current length           |
| setCharAt() | Modifies a character             |
| charAt()    | Gets a character                 |
| substring() | Extracts part of the string      |

---

# Important Points

- `StringBuffer` is **synchronized** → Thread-safe

- Slower than `StringBuilder`

- Used in multi-threaded environments

- Mutable (modifiable)
