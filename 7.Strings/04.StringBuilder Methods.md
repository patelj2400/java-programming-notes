## StringBuilder Methods in Java

---

## 1. append()

Adds data at the **end of the StringBuilder**.

Example:

    StringBuilder sb = new StringBuilder("Hello");
    sb.append(" World");

    System.out.println(sb); // Hello World

✔ Common in DSA for **building strings efficiently**

---

## 2. insert()

Inserts data at a **specific index**.

Example:

    StringBuilder sb = new StringBuilder("Helo");
    sb.insert(3, "l");

    System.out.println(sb); // Hello

Syntax

    insert(index, value)

---

## 3. delete()

Deletes characters from a **range of indexes**.

    StringBuilder sb = new StringBuilder("HelloWorld");
    sb.delete(5, 10);

    System.out.println(sb); // Hello

Syntax

    delete(startIndex, endIndex)

⚠ `endIndex` is **exclusive**

---

## 4. deleteCharAt()

Deletes **one character** at a specific index.

    StringBuilder sb = new StringBuilder("Hello");
    sb.deleteCharAt(1);

    System.out.println(sb); // Hllo

---

## 5. replace()

Replaces characters between indexes.

    StringBuilder sb = new StringBuilder("Hello");
    sb.replace(1, 4, "i");

    System.out.println(sb); // Hio

---

## 6. reverse()

Reverses the string.

    StringBuilder sb = new StringBuilder("Java");
    sb.reverse();

    System.out.println(sb); // avaJ

**Very useful in DSA string problems**

---

## 7. charAt()

Returns character at given index.

    StringBuilder sb = new StringBuilder("Hello");

    System.out.println(sb.charAt(1)); // e

---

## 8. setCharAt()

Changes character at a specific index.

    StringBuilder sb = new StringBuilder("Hello");
    sb.setCharAt(0, 'Y');

    System.out.println(sb); // Yello

---

## 9. length()

Returns length of the string.

    StringBuilder sb = new StringBuilder("Hello");

    System.out.println(sb.length()); // 5

---

## 10. capacity()

Returns current **storage capacity**.

    StringBuilder sb = new StringBuilder();

    System.out.println(sb.capacity()); // 16

Default capacity = **16**

---

## 11. ensureCapacity()

Ensures minimum capacity.

    StringBuilder sb = new StringBuilder();
    sb.ensureCapacity(50);

---

## 12. toString()

Converts `StringBuilder` → `String`.

    StringBuilder sb = new StringBuilder("Hello");

    String str = sb.toString();

---

# Important Methods for DSA

Most commonly used in coding problems:

| Method         | Use               |
| -------------- | ----------------- |
| append()       | build string      |
| reverse()      | reverse string    |
| charAt()       | access characters |
| setCharAt()    | modify character  |
| deleteCharAt() | remove character  |
| length()       | string size       |
| toString()     | convert to String |

---

# Time Complexity (Important for DSA)

| Operation | Complexity |
| --------- | ---------- |
| append    | O(1)       |
| charAt    | O(1)       |
| setCharAt | O(1)       |
| delete    | O(n)       |
| insert    | O(n)       |
| reverse   | O(n)       |
