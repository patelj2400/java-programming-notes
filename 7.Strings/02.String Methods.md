# String Methods in Java

---

## 1. Length & Character Access

#### `length()`

Returns number of characters.

    String s = "Hello";
    System.out.println(s.length()); // 5

---

#### `charAt(index)`

Returns character at given index.

    System.out.println(s.charAt(1)); // 'e'

    ⚠️ Index starts from 0.

---

## 2. Substring Methods (Very Important for DSA)

#### `substring(beginIndex)`

    String s = "abcdef";
    System.out.println(s.substring(2)); // "cdef"

#### `substring(beginIndex, endIndex)`

    System.out.println(s.substring(1,4)); // "bcd"

⚠️ `endIndex` is **exclusive**

👉 Used in:

- Palindrome problems

- Sliding window

- Partitioning problems

---

## 3. Comparison Methods (Interview Favorite)

#### `equals()`

    String a = "hello";
    String b = "hello";
    System.out.println(a.equals(b)); // true

---

#### `equalsIgnoreCase()`

    "HELLO".equalsIgnoreCase("hello"); // true

---

#### `compareTo()`

Lexicographical comparison.

    "apple".compareTo("banana"); // negative

Used in:

- Sorting strings

- Custom comparator logic

---

## 4. Searching Methods

#### `contains()`

    "Java Programming".contains("Java"); // true

---

#### `indexOf()`

    "banana".indexOf("na"); // 2

Returns first occurrence index.

---

#### `lastIndexOf()`

    "banana".lastIndexOf("na"); // 4

---

## 5. Case Conversion

    String s = "Java";

    s.toUpperCase(); // "JAVA"
    s.toLowerCase(); // "java"

---

## 6. Trim & Replace

#### `trim()`

Removes leading & trailing spaces.

    " hello ".trim(); // "hello"

---

#### `replace()`

    "banana".replace('a','o'); // "bonono"

---

#### `replaceAll()` (Regex based)

    "abc123".replaceAll("[0-9]", ""); // "abc"

---

## 7. Splitting Strings (Very Important in DSA)

#### `split()`

    String s = "one,two,three";
    String[] arr = s.split(",");

👉 Used in:

- Word problems

- Frequency counting

- Parsing input

---

## 8. Conversion Methods

#### String → Number

    int num = Integer.parseInt("123");

#### Number → String

    String s = String.valueOf(123);

#### `toCharArray()`

    char[] arr = "Java".toCharArray();

---

## 9. Checking Empty

    "".isEmpty(); // true
    " ".isEmpty(); // false

---

## 10. String Joining

    String.join("-", "2026", "03", "03");
    // "2026-03-03"

---

## VERY IMPORTANT (Interview Concept)

## ⚡ Strings Are Immutable

    String s = "hello";
    s.concat(" world");
    System.out.println(s); // still "hello"

👉 Because String is immutable.

To modify frequently → use:

- `StringBuilder`

- `StringBuffer`

✔ String is immutable
✔ Stored in String Constant Pool
✔ == compares references
✔ equals() compares content
✔ String methods always return new object
