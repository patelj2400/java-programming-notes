## 1.What is Control Flow?

**Control Flow** is the order in which statements in a program are executed.

When your Java program runs, the JVM executes code **top → down → line by line.** --- unless you change that order using control flow statements.

In simple words:

In **Java**, control flow decides:

- Which code runs

- When it runs

- How many times it runs

- Whether it runs at all

## 2.Why Control Flow is Important (DSA Perspective)

In Data Structures & Algorithms:

- You use **conditions** to make decisions (e.g., search success/failure)

- You use **loops** to iterate arrays, lists, trees, graphs

- You use **recursion** to solve divide-and-conquer problems

> Without control flow → No logic → No algorithms.

---

## 3.Types of Control Flow in Java

There are mainly **3 types**:

### 1️⃣ Sequential Flow (Default Flow)

Code runs from top to bottom.

    System.out.println("Start");
    System.out.println("Learning Java");
    System.out.println("End");

Execution order:

    Start
    Learning Java
    End

No jumps. No conditions. Simple execution.

---

### 2️⃣ Selection (Decision-Making Statements)

Used when you want to execute code **based on a condition**.
➡ Condition decides execution path.

- `if`

- `if-else`

- `else-if`

- `switch`

#### 🔹 if Statement

    int age = 18;

    if (age >= 18)
    {
        System.out.println("Eligible to vote");
    }

👉 Executes only if condition is true.

---

#### 🔹 if-else

    if (age >= 18)
    {
        System.out.println("Adult");
    } else
    {
        System.out.println("Minor");
    }

---

#### 🔹 else-if Ladder

    int marks = 75;

    if (marks >= 90)
    {
        System.out.println("Grade A");
    }
    else if (marks >= 70)
    {
        System.out.println("Grade B");
    }
    else
    {
        System.out.println("Grade C");
    }

---

#### 🔹 switch Statement

Best when checking multiple fixed values.

    int day = 2;

    switch(day)
    {
        case 1: System.out.println("Monday"); break;
        case 2: System.out.println("Tuesday"); break;
        default: System.out.println("Invalid");
    }

---

### 3️⃣ Iteration (Loops)

Used to repeat code multiple times.

- `for`

- `while`

- `do-while`

#### 🔹 for Loop

Best when number of iterations is known.

    for (int i = 1; i <= 5; i++)
    {
        System.out.println(i);
    }

---

#### 🔹 while Loop

Used when condition-based repetition is needed.

    int i = 1;

    while (i <= 5)
    {
        System.out.println(i);
        i++;
    }

---

#### 🔹 do-while Loop

Runs at least once.

    int i = 1;

    do {
        System.out.println(i);
        i++;
    }
    while (i <= 5);

---

## 4️⃣ Control Transfer Statements

Used to transfer control immediately.

- `break`

- `continue`

- `return`

These change the normal flow inside loops:

#### 🔹 break → exits loop immediately

#### 🔹 continue → skips current iteration

#### 🔹 return → exits method

Example:

    for (int i = 1; i <= 5; i++)
    {
        if (i == 3) break;
        System.out.println(i);
    }

Output:

    1
    2

---

## 4. Visual Understanding

Think of control flow like:

- **Sequential** → Straight road

- **If-Else** → Road with decision junction

- **Loops** → Circular track

- **Break/Return** → Emergency exit

## 5.Interview-Level Understanding

##### Q1:What is the difference between break and continue?

👉 Here is:

- **break** → exits loop completely

- **continue** → skips only one iteration

##### Q2:Can we use switch with String in Java?

👉 Yes (Java 7+)

##### Q3:Why is control flow important in recursion?

👉 Because recursion depends on:

- Base condition (decision)

- Recursive call (repetition)

# 🧠 Real DSA Example

Searching an element in array:

    int[] arr = {10, 20, 30, 40};
    int target = 30;

    for (int num : arr)
    {
        if (num == target)
        {
            System.out.println("Found");
            break;
        }
    }

Here:

- Loop → iteration

- if → decision

- break → control transfer

## Final Definition (Best Interview Answer)

> Control Flow is the mechanism that determines the order in which statements execute in a program using sequential execution, decision-making statements, loops, and control transfer statements.
