# Conditions (Control Statements)

---

## What Are Conditions?

**Conditions** are decision-making statements in programming.

They allow your program to:

- Execute certain code **only if a condition is true**

- Skip or choose between blocks of code

👉 In simple words:

> Conditions help your program **think and decide**.
> They control the flow of execution.

---

## Why Conditions Are Important?

##### Without conditions:

- Programs would execute line by line only

- No decision making

- No dynamic behavior

##### With conditions:

- Login validation

- ATM withdrawal logic

- Grade calculation

- Even/odd check

- Game logic

---

## 1. if Statement

- Executes code only if condition is true.

#### Syntax:

    if (condition) {
    // code runs if condition is true
    }

#### Flow:

- Condition checked → `true` → block executes

- If `false` → block skipped

#### Example:

    int age = 20;

    if (age >= 18) {
        System.out.println("Eligible to vote");
    }

#### How it works:

- Condition → `age >= 18`

- If TRUE → Code runs

- If FALSE → Skipped

---

## 2. if-else Statement

- Executes one block if condition is true, otherwise another block.

- Used when you want **either this OR that**

#### Syntax:

    if (condition) {
        // if true
    } else {
        // if false
    }

#### Example:

    int age = 16;

    if (age >= 18) {
        System.out.println("Adult");
    } else {
        System.out.println("Minor");
    }

👉 Very common in DSA for:

- Even/Odd

- Positive/Negative

- Greater/Smaller

---

## 3. if-else-if Ladder

Used when multiple conditions are possible.

#### Syntax:

    if (condition1) {

    } else if (condition2) {

    } else {

    }

#### Example:

    int marks = 75;

    if (marks >= 90) {
        System.out.println("Grade A");
    } else if (marks >= 75) {
        System.out.println("Grade B");
    } else if (marks >= 50) {
        System.out.println("Grade C");
    } else {
        System.out.println("Fail");
    }

👉 Conditions are checked top to bottom.
👉 First true condition executes.

---

## 4.Nested if

if inside another if.

    int age = 25;
    boolean hasLicense = true;

    if (age >= 18) {
        if (hasLicense) {
            System.out.println("You can drive");
        }
    }

👉 Used in:

- Authentication logic

- Multi-level validation

- Matrix problems in DSA

## 5.switch Statement

Used when checking a variable against multiple values.

- The `switch` expression is evaluated once.
- The result is compared with each `case` value.
- If there is a match, the matching block of code runs.
- The `break` statement stops the switch after the matching case has run.
- The `default` statement runs if there is no match.

#### Syntax:

    switch (variable)
    {
        case value1:
            // code
            break;

        case value2:
            // code
            break;

        default:
            // default code

    }

#### Example:

    int day = 2;

    switch (day)
    {
        case 1:
            System.out.println("Monday");
            break;
        case 2:
            System.out.println("Tuesday");
            break;
        default:
            System.out.println("Invalid day");
    }

👉 When to Use `switch`?

- Fixed values
- Menu-driven programs
- Mapping integers to actions
- Avoids long if-else chains
- More readable
- Cleaner

👉 What is break in Switch?

- break stops the execution after a case is matched.

- If we don’t use break, then all cases below it will execute.
  This is called fall-through.

👉 What is Default Case?

- The default block runs when none of the cases match.
- It is similar to else in if-else.

### Advanced Switch (Java 14+)

Modern Java supports arrow syntax:

    switch(fruit) {
        case "mango" -> System.out.println("King");
        case "apple" -> System.out.println("Doctor away");
        default -> System.out.println("Invalid");
    }

No need for `break` here.

## 6. Ternary Operator (Short if-else)

    int age = 20;
    String result = (age >= 18) ? "Adult" : "Minor";
    System.out.println(result);

👉 Used for:

- Finding min/max

- Simple assignments

- Cleaner DSA code

## Switch vs If-Else

### 🟢 Use if-else when:

- You have range-based conditions

- Complex logical conditions

Example:

    if (marks >= 90) {
    System.out.println("A Grade");
    }

### 🟢 Use switch when:

- You compare one variable to many exact values

- Cleaner alternative to multiple else-if

## Interview-Level Understanding

#### 1.What happens internally?

👉 When Java sees:

    if (age >= 18)

1.  Expression is evaluated

2.  It returns `true` or `false`

3.  JVM decides which block to execute

👉 Conditions always return **boolean**

#### 2.Can we use `double` in switch?

👉 Not allowed (only byte, short, int, char, String, enum)

#### 3.What happens if we remove `break` in switch?

👉 Execution continues to next case (fall-through).

#### 4.Difference between `if` and `switch`?

| if                | switch                         |
| ----------------- | ------------------------------ |
| Works with ranges | Works with fixed values        |
| More flexible     | Cleaner for many fixed options |
