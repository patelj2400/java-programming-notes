## 1.Why must `main` be `static`?

    public static void main(String[] args)

#### Reason:

Because **JVM calls `main()` without creating an object** of the class.

##### Q: What happens internally?

When you run:

    java Main

The **JVM**:

1.  Loads the `Main` class into memory.

2.  Looks for:

        public static void main(String[] args)

3.  Calls it directly using the class name.

👉 Since no object is created, `main()` must belong to the **class itself**, not to an object.

That's why it must be `static`.

---

## 2.What if `main` was not static?

    public void main(String[] args)

Then JVM would need:

    Main obj = new Main();
    obj.main(args);

But JVM does NOT create objects automatically.

So program won't run.

---

## 3.Can we overload `main()`?

👉 YES, we can overload `main()`.

Example:

    public class Test {

        public static void main(String[] args) {
            System.out.println("Original main");
            main(10);
        }

        public static void main(int x) {
            System.out.println("Overloaded main: " + x);
        }

    }

### Output:

    Original main
    Overloaded main: 10

#### Important: JVM will **only call**:

    public static void main(String[] args)

Other overloaded versions must be called manually.

---

## 3.Can a program run without `main()`?

### Case 1: Normal Java Application

❌ NO. It cannot run.

Because JVM starts execution from `main()`.

---

### Case 2: Special Frameworks

Some frameworks do not require traditional `main()`:

- Servlets (runs inside server)

- Spring Boot (internally uses main)

- JavaFX (uses Application class)

- Applets (deprecated)

In these cases, execution starts from framework lifecycle methods, not directly from main.

---

### Trick Case (Static Block Execution -- Old Trick)

In older Java versions, this worked:

    public class Test {
        static {
            System.out.println("Static block executed");
            System.exit(0);
        }
    }

But in modern Java, it will give error:

Main method not found

So now ❌ main is mandatory.

## 4.What happens if class name and file name differ?

This is VERY important.

## ✅ Rule:

If class is `public`, then:

> File name MUST match class name.

Example:

    public class Student {
    }

File name must be:

    Student.java

---

## ❌ If different:

If file name is `Test.java` but class is:

    public class Student {
    }

Compilation error:

> class Student is public, should be declared in a file named Student.java

---

## 🔹 What if class is NOT public?

Then file name and class name can differ.

Example:

    class Student {
    }

File name can be anything.

But:

- Only one public class allowed per file.
- File name must match public class.

# 🧠 Advanced Interview Follow-Up

### Q:Can `main` be private?

No. JVM won't find it.

### Q:Can `main` return int?

No. Must return `void`.

### Q:Can we write `static public void main`?

Yes. Order doesn't matter.
