# Loops in Programming

---

## 1.What is a Loop?

A **loop** is used to execute a block of code **multiple times** (repeatedly) until a condition becomes false.

👉 Instead of writing code 100 times, we use a loop.

#### Example (Without Loop ❌)

    System.out.println("Hello");
    System.out.println("Hello");
    System.out.println("Hello");

#### Example (With Loop ✅)

    for(int i = 0; i < 3; i++) {
    System.out.println("Hello");
    }

---

## 2.Types of Loops in Java

1.  **for loop**

2.  **while loop**

3.  **do-while loop**

4.  **Enhanced for loop (for-each)**

---

### A.For Loop

> Used when number of iterations is known

#### Syntax:

    for(initialization; condition; update) {
    // code
    }

#### Example:

    public class LoopExample {
        public static void main(String[] args) {

            for(int i = 1; i <= 5; i++) {
                System.out.println(i);
            }

        }
    }

#### How it works:

1.  `int i = 1` → initialization

2.  `i <= 5` → condition check

3.  Executes body

4.  `i++` → increment

5.  Repeat

### DSA Usage:

- Traversing arrays

- Running nested loops

- Pattern printing

- Time complexity problems

---

### B.While Loop

> Used when number of iterations is NOT known

#### Syntax:

    while(condition) {
        // code
    }

#### Example:

    int i = 1;
    while(i <= 5)
    {
        System.out.println(i);
        i++;
    }

#### Real-life Example:

Keep taking input until user enters `0`.

    int num = 1;
    while(num != 0)
    {
        num = sc.nextInt();
    }

> 👉 Condition checked before execution.

---

### C.Do-While Loop

> Executes at least once (condition checked at end) (even if condition is false.)
> 👉 Condition checked after execution.

#### Syntax:

    do {
        // code
    }
    while(condition);

#### Example:

    int i = 1;
    do
    {
        System.out.println(i);
        i++;
    }
    while(i <= 5);

👉 Even if condition is false initially, it runs once.

---

### D.Enhanced For Loop (For-Each)

> Used to iterate over arrays or collections.

#### Syntax:

    for(dataType variable : array){
        // code
    }

#### Used for arrays & collections

    int[] arr = {10, 20, 30};

    for(int num : arr) {
        System.out.println(num);
    }

👉 Cleaner syntax
👉 Cannot modify index directly

## 3.Loop Control Statements

- break; // exits loop completely
- continue; // skips current iteration

### 1.break

The `break` statement can also be used to jump out of a loop.

> Stops the loop immediately.

    for(int i = 1; i <= 10; i++)
    {
        if(i == 5) break;
        System.out.println(i);
    }

Output:

    1 2 3 4

---

### 2.continue

The `continue` statement breaks one iteration (in the loop), if a specified condition occurs, and continues with the next iteration in the loop.

> Skips current iteration.

    for(int i = 1; i <= 5; i++) {
        if(i == 3) continue;
        System.out.println(i);
    }

Output:

    1 2 4 5

## Memory + Execution View (Important)

- Loop variable (`i`) is stored in **stack memory**.
- Each iteration updates the same variable --- not creating new memory.

## Loop & Time Complexity (Interview Angle)

| Loop Type          | Example                 | Time Complexity |
| ------------------ | ----------------------- | --------------- |
| Single loop        | `for(i=0; i<n; i++)`    | O(n)            |
| Nested loop        | 2 loops running n times | O(n²)           |
| Loop dividing by 2 | `i = i/2`               | O(log n)        |

## Interview Important Questions

##### 1. Difference between `while` and `do-while`?

👉

| Feature             | `while` loop          | `do-while` loop        |
| ------------------- | --------------------- | ---------------------- |
| Condition check     | Before execution      | After execution        |
| Execution guarantee | May execute 0 times   | Executes at least once |
| Type                | Entry-controlled loop | Exit-controlled loop   |

##### 2. When to use `for` vs `while`?

👉 Use `for` loop when:

- Number of iterations is known

- Counter-based loops

- Array traversal

> Best for counting.

    for (int i = 0; i < 5; i++) {
        System.out.println(i);
    }

👉 Use `while` loop when:

- Number of iterations is unknown

- Depends on condition

- User input based loops

> Best for condition-based repetition.

    while (scanner.hasNext()) {
        // process input
    }

##### 3. What is infinite loop?

👉 An infinite loop runs forever because the condition never becomes false.

###### Example:

    while (true) {
    System.out.println("Running...");
    }

This never stops unless:

- `break` is used

- Program is terminated

##### 4. How does nested loop affect time complexity?

👉 A nested loop increases time complexity multiplicatively.

###### Example:

    for(int i = 0; i < n; i++) {
        for(int j = 0; j < n; j++) {
            System.out.println(i + " " + j);
        }
    }

Outer loop runs → n times

Inner loop runs → n times

Total operations = n × n = **O(n²)**

| Nested Loops         | Time Complexity     |
| -------------------- | ------------------- |
| 2 loops (n × n)      | O(n²)               |
| 3 loops (n × n × n)  | O(n³)               |
| Dependent inner loop | O(n(n+1)/2) ≈ O(n²) |

##### 5. Can we write infinite for loop? (Yes → `for(;;)`)

👉 YES

    for(;;) {
    System.out.println("Infinite");
    }

👉 Equivalent to:

    while(true) {
    }

Because:

- Initialization → missing

- Condition → missing (treated as true)

- Update → missing

So it becomes an infinite loop.

##### 6.What is the output?

    for(int i = 0; i < 5; i++){
        System.out.println(i);
        i++;
    }

👉 Answer

    0
    2
    4

Because `i++` runs twice (inside loop + for update).

## Interview-Level Quick Summary

- `while` → condition first

- `do-while` → execute at least once

- `for` → best for counting loops

- Infinite loop → condition never false

- Nested loops → multiply time complexity
