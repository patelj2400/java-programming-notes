# Input and Output (I/O) in Programming

Input and Output are the basic ways a program **communicates with the outside world**.

- **Input** → Data given to the program

- **Output** → Data shown or returned by the program

---

## 1.What is Input?

👉 **Input** is the data given to a program by the user or another system.

It can come from:

- Keyboard - User typing a number

- File - Reading data from a file

- Network - Receiving data from a network

- Database - Receiving data from a database

- Sensor - Getting sensor values

#### Example (Real Life)

ATM machine:

- You enter PIN → **Input**
- You enter amount → **Input**

---

## 2.What is Output?

👉 **Output** is the result produced by a program after processing input.

It can be:

- Printed on screen (Console output)

- Saved in file (File output)

- Sent over network (Network response)

- Stored in database (Database output)

#### ATM Example:

- "Transaction Successful" → **Output**

- Cash dispensed → **Output**

---

## 3.Basic Input & Output in Java

### 🔹 Output in Java

#### Using `System.out.println()`

    public class Main {
        public static void main(String[] args) {
            System.out.println("Hello World");
        }
    }

#### Explanation:

- `System` → predefined class

- `out` → output stream

- `println()` → prints text and moves cursor to next line

### 🔹 Other Output Methods:

    System.out.print("Hello ");
    System.out.println("World");

Output:

    Hello World

---

### 🔹 Input in Java (Using Scanner)

To take input from keyboard, Java uses:

👉 `Scanner` class from `java.util` package.

    import java.util.Scanner;

    public class Main {
    public static void main(String[] args) {
            Scanner sc = new Scanner(System.in);

            System.out.print("Enter your age: ");
            int age = sc.nextInt();

            System.out.println("Your age is: " + age);
        }

    }

### Explanation:

- `Scanner sc` → object creation
- `System.in` → input stream (keyboard)
- `nextInt()` → reads integer

## 5.Types of I/O in Java

Java provides I/O mainly through the `java.io` package.

#### 1.Console I/O

- `System.out` → Output

- `Scanner` → Input

#### 2.File I/O

Classes like:

- `File`

- `FileReader`

- `FileWriter`

- `BufferedReader`

- `BufferedWriter`

#### 3.Byte Stream vs Character Stream

| Type             | Used For                   | Example Classes   |
| ---------------- | -------------------------- | ----------------- |
| Byte Stream      | Images, audio, binary data | `FileInputStream` |
| Character Stream | Text data                  | `FileReader`      |

---

## 6.Standard Streams in Java

Java has 3 standard streams:

| Stream       | Purpose         |
| ------------ | --------------- |
| `System.in`  | Standard input  |
| `System.out` | Standard output |
| `System.err` | Error output    |

Example:

    System.err.println("This is an error message");

---

## 7.Compile-Time vs Runtime in I/O

Since you previously studied **Compile Time vs Runtime**, connect this concept:

- I/O happens at **Runtime**

- Compiler does NOT check user input values

- Errors like wrong input type occur at runtime

Example:

    int x = sc.nextInt(); // If user types "abc" → Runtime error

## 6.Input → Process → Output Cycle (IPO Model)

Every program follows:

    Input → Processing → Output

### Example:

Input:

    Enter two numbers: 5 3

Processing:

    5 + 3

Output:

    8

## 7.Interview Perspective (Very Important)

#### Q1: What is the difference between `print()` and `println()` and `printf`?

| print()                           | println()                 |
| --------------------------------- | ------------------------- |
| Does NOT move cursor to next line | Moves cursor to next line |

- `print()` → prints without new line

- `println()` → prints with new line

- `printf()` → formatted output

---

#### Q2: Why is `Scanner` slower in competitive programming?

Because:

- It does parsing

- Uses regular expressions internally

- More overhead

👉 For fast I/O use:

- `BufferedReader`

- `PrintWriter`

#### Q3: What is buffering?

👉 Buffering improves performance by reducing I/O operations.

#### Q4: Is I/O slow or fast?

👉 I/O is generally slow compared to CPU operations because it interacts with external systems.

## 8.Real DSA Example

    import java.util.Scanner;

    public class Sum {
    public static void main(String[] args) {
            Scanner sc = new Scanner(System.in);

            int n = sc.nextInt();
            int sum = 0;

            for(int i = 0; i < n; i++) {
                sum += sc.nextInt();
            }

            System.out.println(sum);
        }

    }

This is typical coding platform pattern:

1.  Read input

2.  Process

3.  Print result
