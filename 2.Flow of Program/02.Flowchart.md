## 1.What is a Flowchart?

A **Flowchart** is a **diagrammatic representation of an algorithm or process**.
A **Flowchart** is a graphical representation of a program's logic.

It shows the **step-by-step execution flow** of a program using **standard symbols** connected by arrows.

Flowcharts help you:

- Understand logic before writing code

- Visualize decision making (`if-else`)

- Design loops (`for`, `while`)

- Solve problems clearly in interviews

It shows:

- Start

- Process

- Decision

- End

## 2.Common Flowchart Symbols

## 1️⃣ Start / End (Terminator)

- Shape: Oval
- Purpose: Represents beginning or end of program

Example:

    Start
    End

---

## 2️⃣ Process

- Shape: Rectangle
- Purpose: Represents calculations or instructions

Example:

    sum = a + b
    i = i + 1

---

## 3️⃣ Input / Output

- Shape: Parallelogram
- Purpose: Used for taking input or displaying output

Example:

    Input number
    Print result

---

## 4️⃣ Decision

- Shape: Diamond
- Purpose: Used for conditions (Yes/No, True/False)

Example:

    Is number > 0?

---

## 5️⃣ Flow Lines (Arrows)

- Shape: Arrow
- Purpose: Shows direction of execution

---

## 3.Simple Example: Check Even or Odd

### Problem:

Input a number and check whether it is even or odd.

### Flowchart Steps:

    1.  Start
    2.  Input number
    3.  Check: number % 2 == 0
    4.  If yes → Print "Even"
    5.  Else → Print "Odd"
    6.  End

---

### 4.Equivalent Java Code

    import java.util.Scanner;

    public class EvenOdd
    {
        public static void main(String[] args)
        {
            Scanner sc = new Scanner(System.in);
            int num = sc.nextInt();

            if (num % 2 == 0) {
                System.out.println("Even");
            } else {
                System.out.println("Odd");
            }
        }
    }

Flowchart representation:

<pre>
        (Start)
           ↓
       [Input n]
           ↓
        &lt;n%2==0&gt;
        /        \
     Yes          No
      ↓            ↓
 [Print Even]  [Print Odd]
        \        /
           ↓
          (End)
</pre>

### 5.Example with Loop (Print 1 to 5)

Flow Logic:

    1.  Start
    2.  i = 1
    3.  Is i <= 5
    4.  Print i
    5.  i++
    6.  Repeat step 3
    7.  End

This represents a `while` loop in Java.

## 6.Common Flowchart Symbols

| Symbol Shape    | Name             | Purpose                 |
| --------------- | ---------------- | ----------------------- |
| 🟢 Oval         | **Terminator**   | Start / End             |
| ▭ Rectangle     | **Process**      | Calculation / Statement |
| ◇ Diamond       | **Decision**     | Condition (Yes/No)      |
| ➡ Arrow         | **Flow line**    | Direction of flow       |
| ⬭ Parallelogram | **Input/Output** | Read / Print            |

## 7.Why Flowcharts Are Important in DSA

Since you're learning Control Flow:

| Java Concept         | Flowchart Symbol      |
| -------------------- | --------------------- |
| Sequential execution | Process box           |
| if-else              | Decision diamond      |
| Loops                | Decision + arrow back |
| Input/Output         | Parallelogram         |

In interviews:

- Many interviewers ask you to **explain logic before coding**
- Flowchart thinking improves structured problem solving

> Control Flow determines the execution order of statements in a program and is managed using conditional statements, loops, and jump statements.
