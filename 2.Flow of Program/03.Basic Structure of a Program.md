## 1.What is a Program?

A **program** is a set of instructions written in a programming language that tells the computer what to do.

👉 Every program has a **starting point**, **logic**, and an **ending point**.

---

## 2.Basic Structure

    → Start
    → Take Input
    → Process Data
    → Give Output
    → End

#### Example 1: Print Hello Name

**Problem:** Take name as input and print: Hello name

**Flow:**

    Start
    Input name
    Print "Hello " + name
    End

**Example:**

    Input: Kunal
    Output: Hello Kunal

## 3.Basic Structure of a Java Program

Here is the simplest Java program:

    package mypackage;

    import java.util.*;

    public class Main {
        public static void main(String[] args) {
            System.out.println("Hello World");
        }
    }

Now let's break it step by step 👇

---

#### 1. Package Declaration (Optional)

- Groups related classes.

- Must be first line (if present).

        package mypackage;

---

#### 2. Import Statements (Optional)

- Used to import built-in or external classes.

      import java.util.Scanner;

---

#### 3. Class Declaration

Every Java program must have at least one class.

    public class Main {

- `public` → Access modifier

- `class` → Keyword to define a class

- `Main` → Class name

> In Java, **everything must be inside a class**.

---

#### 4. Main Method (Entry Point)

    public static void main(String[] args)

This is the **starting point** of the program.

- `public` → JVM can access it (Accessible from anywhere)

- `static` → No object needed (Belongs to class)

- `void` → Returns nothing

- `main` → Method name

- `String[] args` → Command line arguments

> JVM always starts execution from `main()`.

---

#### 5. Program Statements (Logic Section)

    System.out.println("Hello World");

This is where your **logic** goes.

Examples:

- Variables
- Conditions
- Loops
- Function calls
- Object creation

---

## 3.General Structure of Any Program (Language Independent)

Every program usually has:

## 4.Full Java Structure (Realistic Example)

    // 1. Package (optional)
    package com.example;

    // 2. Import statements
    import java.util.Scanner;

    // 3. Class definition
    public class Calculator {

        // 4. Variables
        int a, b;

        // 5. Method
        int add(int x, int y) {
            return x + y;
        }

        // 6. Main method
        public static void main(String[] args) {

            // 7. Statements (Program Logic)
            Calculator obj = new Calculator();

            int result = obj.add(10, 20);

            System.out.println("Result: " + result);
        }

    }

## 7.Memory View (Important for DSA)

When program runs:

- **Stack** → Stores method calls & local variables

- **Heap** → Stores objects

- **Method Area** → Class information

Example:

    Calculator obj = new Calculator();

- `obj` → Stored in Stack

- `new Calculator()` → Object stored in Heap

#### Memory Perspective

When program runs:

1.  **Class is loaded into Method Area**

2.  `main()` is pushed into **Stack**

3.  Variables inside `main()` stored in **Stack**

4.  Objects created using `new` stored in **Heap**

## Interview-Level Questions

##### Q1:What is the entry point of a Java program?

👉 public static void main(String[] args)

##### Q2:Can we run a Java program without main method?

👉 No (except special cases like Servlets, Spring Boot, etc.)

##### Q3:Why is main method static?

👉 Because JVM calls it without creating an object.

##### Q4:Why must `main` be static?

👉 Because JVM calls main() without creating an object of the class.

##### Q5:Can we overload `main`?

👉 YES, we can overload main().

##### Q6:Can program run without `main`?

👉 NO. It cannot run.

##### Q7:What happens if class name and file name differ?

👉 If a public class name and file name differ in Java, compilation fails with an error.
