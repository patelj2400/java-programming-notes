# Java Math Class

---

The **`Math`** class in Java is part of the
Oracle Corporation's **`java.lang.Math`** package.

It provides **static methods** for performing mathematical operations like power, square root, rounding, min/max, etc.

👉 No need to import it because `java.lang` is imported by default.
👉 All methods are **static**, so we call them using `Math.methodName()`.

---

## 1. Important Java Math Methods

---

### 1. `Math.max()` -- Maximum Value

Returns the **largest of two numbers**.

    Math.max(10, 20);

Example:

    System.out.println(Math.max(10, 20));

Output

    20

---

### 2. `Math.min()` -- Minimum Value

Returns the **smallest of two numbers**.

    System.out.println(Math.min(10, 20));

Output

    10

---

### 3. `Math.sqrt()` -- Square Root

    System.out.println(Math.sqrt(64));

Output

    8.0

Return type → `double`

---

## 4. `Math.abs()` -- Absolute Value

Returns the **positive value**.

    System.out.println(Math.abs(-10));

Output

    10

---

## 5. `Math.pow()` -- Power

    System.out.println(Math.pow(2, 3));

Output

    8.0

Meaning:

    2³ = 8

---

## 6. `Math.round()` -- Round Value

    System.out.println(Math.round(4.6));

Output

    5

---

## 7. `Math.ceil()` -- Round Up

Always **rounds upward**.

    System.out.println(Math.ceil(4.1));

Output

    5.0

---

## 8. `Math.floor()` -- Round Down

Always **rounds downward**.

    System.out.println(Math.floor(4.9));

Output

    4.0

---

## 9. `Math.random()` -- Random Number

Generates a **random number between 0.0 and 1.0**

    System.out.println(Math.random());

Example Output

    0.56734

Generate number **0--100**

    int num = (int)(Math.random() * 10) + 1;
    System.out.println(num);

---

## 10. `Math.floor()`

Rounds down.

    System.out.println(Math.floor(5.9)); // 5.0

Example Output

    5.0

# 3. Trigonometric Methods (Advanced)

| Method             | Description       |
| ------------------ | ----------------- |
| `Math.sin()`       | Sine              |
| `Math.cos()`       | Cosine            |
| `Math.tan()`       | Tangent           |
| `Math.toRadians()` | Degrees → Radians |
| `Math.toDegrees()` | Radians → Degrees |

Example:

    System.out.println(Math.sin(Math.toRadians(90)));

Output

    1.0

# 4. Example Program

    public class MathExample {
        public static void main(String[] args) {
            System.out.println("Max: " + Math.max(10, 20));
            System.out.println("Min: " + Math.min(10, 20));
            System.out.println("Square Root: " + Math.sqrt(36));
            System.out.println("Power: " + Math.pow(2, 5));
            System.out.println("Absolute: " + Math.abs(-50));
            System.out.println("Random: " + Math.random());
        }
    }

Output (example)

    Max: 20
    Min: 10
    Square Root: 6.0
    Power: 32.0
    Absolute: 50
    Random: 0.7283

# 5. Important DSA Use Cases

In **DSA problems**, `Math` is used for:

- Finding **maximum / minimum**

- **Power calculations**

- **Absolute differences**

- **Square root optimization**

- **Random testing**

- **Geometry problems**

Example:

    int diff = Math.abs(a - b);

Useful in **array and greedy problems**.

# . Interview Points

✔ `Math` class is **final** (cannot be inherited).
✔ Constructor is **private** (cannot create object).
✔ All methods are **static**.
✔ Works mainly with `double`.
✔ `Math.pow()` returns **double**, so cast if needed.

    int x = (int)Math.pow(2,3);
