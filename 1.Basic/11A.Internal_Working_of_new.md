### What actually happens when you use `new`

1.  **Memory allocation (Heap)**
    - The JVM allocates memory in the **heap** for the new object.
    - The size is determined by the class definition (all instance variables).
2.  **Default initialization**
    - All instance variables are set to default values:
      - `0` for numbers
      - `false` for booleans
      - `null` for object references
3.  **Constructor execution**
    - The constructor is called.
    - It initializes the object with actual values (overwrites defaults if specified).
4.  **Reference assignment**
    - The reference variable (like `myCar` or `s1`) is stored in **stack memory**.
    - It holds the **address (reference)** of the object in the heap.

---

### Important correction to your points

- ✅ "Object is created in heap memory" → Correct
- ⚠️ "Memory is allocated for variables" → More precisely:
  - Memory is allocated for **instance variables inside the object**
  - Local variables are **not** part of the object; they live in the stack
- ✅ "Constructor runs" → Correct
- ✅ "Reference variable stores address" → Correct

---

    Car myCar = new Car();

**Breakdown:**

- `new Car()` → creates object in heap + runs constructor
- `myCar` → reference variable in stack storing object address

### 1. Instance Variables

**Definition:** Variables declared inside a class but **outside any method/constructor/block**.

#### Key points:

- Belong to an **object (instance)**
- Stored in **heap memory** (as part of the object)
- Have **default values** (`0`, `null`, `false`, etc.)
- Accessible by all methods of the class (depending on access modifiers)

#### Example:

    class Car {
        int speed; // instance variable
    }

---

### 2. Local Variables

**Definition:** Variables declared **inside a method, constructor, or block**.

#### Key points:

- Belong to a **method/block**, not the object
- Stored in **stack memory**
- **No default values** → must be initialized before use
- Accessible **only within that method/block**

#### Example:

    void drive() {
        int distance = 100; // local variable
    }

---

### 3. Side-by-side comparison

| Feature         | Instance Variable            | Local Variable              |
| --------------- | ---------------------------- | --------------------------- |
| Declared        | Inside class, outside method | Inside method/block         |
| Belongs to      | Object                       | Method/block                |
| Memory location | Heap                         | Stack                       |
| Default values  | Yes                          | No                          |
| Lifetime        | As long as object exists     | Until method execution ends |
| Access          | Throughout class             | Only within block           |

---

### 4. Quick intuition

- **Instance variable → "Object's properties"**\
  (e.g., a car's speed, color)
- **Local variable → "Temporary working data"**\
  (e.g., distance calculated during a trip)

### "Constructor execution" --- what actually happens?

When you write:

    Car myCar = new Car();

After memory is created and default values are set, this line runs:

👉 **The constructor is called**

---

### What is a constructor?

A **constructor** is a special method in a class that:

- Has the **same name as the class**
- Runs **automatically when an object is created**
- Is used to **initialize the object**

---

### "Initializes the object" --- meaning

It means:
👉 The constructor gives **real/desired values** to variables instead of default ones.

---

### Example

    class Car {
    int speed;

        Car() {
            speed = 100;  // constructor sets value
        }

    }

#### Step-by-step:

1.  Object created → `speed = 0` (default)
2.  Constructor runs → `speed = 100`

👉 So the constructor **overwrites the default value**

---

### Another example with parameters

    class Car {
    int speed;

        Car(int s) {
            speed = s;
        }

    }

    Car c1 = new Car(80);
    Car c2 = new Car(120);

👉 Now each object gets **different values**:

- `c1.speed = 80`
- `c2.speed = 120`

---

#### Simple meaning in one line

👉 **Constructor execution = setting up the object with proper initial values right after it is created**
