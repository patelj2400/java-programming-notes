## What is a Class in Java?

In **Java**, a **Class** is a **blueprint (template)** used to create objects.

It defines:

- ✅ **Variables (Data / Properties)**

- ✅ **Methods (Functions / Behavior)**

Think of a class as a **design**, and objects as the **real-world things created from that design**.

---

## Real-Life Example

#### Example: House Blueprint

- Blueprint = **Class**

- Actual House = **Object**

The blueprint defines:

- Number of rooms

- Color

- Area

- Door type

But the real house is created using that blueprint.

---

## Structure of a Class

    access_modifier class ClassName {

        // Variables (State)

        // Constructors

        // Methods (Behavior)
    }

Example:

    public class Car {

        String brand; // property (instance variable)
        int speed;

        Car(String b, int s) {   // Constructor
            brand = b;
            speed = s;
        }

        void drive() { // method behavior
            System.out.println(brand + " is driving at " + speed);
        }
    }

Here:

- `Car` is a class.

- `brand` and `speed` are variables (state).

- `drive()` is a method (behavior).

## Programming Example

#### Class Definition

    class Student {
        String name;     // variable (property)
        int age;

        void study() {   // method (behavior)
            System.out.println(name + " is studying");
        }
    }

Here:

- `Student` → Class name

- `name`, `age` → Instance variables

- `study()` → Method

---

## Creating an Object

    public class Main {
        public static void main(String[] args) {

            Student s1 = new Student();  // Object creation

            s1.name = "Jay";
            s1.age = 22;

            s1.study();  // Calling method
        }
    }

#### Output:

    Jay is studying

Here:

- `s1` is an object of the class `Student`.

- The class defines what the object can store and do.

---

## Important Points About Class

1.  A class is a **reference type**

2.  Memory is allocated only when object is created using `new`

3.  One class can create multiple objects

4.  Java is a **class-based language**

5.  Everything in Java is inside a class (except primitive types)

## Key Points

- A class is a **blueprint**, not the actual object.

- Objects are **instances** of a class.

- A class can contain:
  - Variables (fields)

  - Methods

  - Constructors

  - Blocks

  - Nested classes

## What is an Object in Java?

In **Java**, an **Object** is a **real-world entity created from a class**.

If a **class is a blueprint**,\
then an **object is the actual implementation of that blueprint**.

---

## Simple Definition

**An object is an instance of a class that contains data and behavior.**

It represents a real-world entity and contains:

- **State** → stored in variables (fields)

- **Behavior** → defined by methods

- **Identity** → a unique reference in memory

---

## 🔹 Real-Life Example

### 🚗 Car Example

- **Class** → Car (design/blueprint)

- **Object** → BMW, Audi, Tesla (actual cars)

Each car:

- Has properties → color, speed, brand

- Has behavior → start(), stop(), accelerate()

---

## 🔹 Technical Definition

An object has **3 main characteristics**:

1.  ✅ **State** → Variables (data)

2.  ✅ **Behavior** → Methods (functions)

3.  ✅ **Identity** → Unique memory location

---

## 🔹 Java Example

### Step 1: Create a Class

    class Student {
    String name;
    int age;

        void study() {
            System.out.println(name + " is studying");
        }

    }

### Output:

    Jay is studying

---

### Step 2: Create an Object

    class Car {
        String brand;
        int speed;

        void drive() {
            System.out.println("The car is driving");
        }
    }

### Creating an Object:

    public class Main {
        public static void main(String[] args) {
            Car myCar = new Car();   // object created

            myCar.brand = "Toyota";
            myCar.speed = 120;

            myCar.drive();
        }
    }

Here:

- `myCar` is an **object**

- `Car` is the **class**

- `new Car()` creates the object in memory

---

## 🔹 How Object is Created (Memory View)

When we write:

    Student s1 = new Student();

### What happens internally?

1.  `new` keyword creates object in **Heap Memory**

2.  Memory is allocated for variables

3.  Constructor runs

4.  Reference variable (`myCar`) or (s1) stores the address

        Stack Memory        Heap Memory
        -------------       ----------------
        myCar   ---------->   Car Object
        brand = null
        speed = 0

# Difference Between Class and Object

| Feature    | Class                             | Object                        |
| ---------- | --------------------------------- | ----------------------------- |
| Definition | Blueprint or template             | Instance of a class           |
| Memory     | No memory allocated when declared | Memory allocated when created |
| Purpose    | Defines properties & behaviors    | Represents real-world entity  |
| Creation   | Declared using `class` keyword    | Created using `new` keyword   |
| Example    | `class Car {}`                    | `Car myCar = new Car();`      |
