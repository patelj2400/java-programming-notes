# 💻 Types of Programming Languages

Programming languages can be classified in different ways --- based on **level**, **paradigm**, and **purpose**.

**Paradigm** :A programming paradigm is a fundamental style, approach, or methodology for structuring and solving problems in code

---

## 1️⃣ Based on Level (Low-Level vs High-Level)

### (i) Low-Level Languages

These are close to machine code (0s and 1s).

#### Machine Language

- Binary code

- Directly understood by CPU

- Very hard for humans

Example:

    10101010 00001111

#### Assembly Language

- Uses mnemonics like MOV, ADD

- Needs an assembler

- Used in embedded systems

---

### (iI) High-Level Languages

These are easy to read and closer to human language.

### Examples:

##### 🟦 Java

- Object-Oriented

- Used in Android & enterprise apps

##### 🟨 Python

- Simple syntax

- Used in AI, automation

##### 🟧 C++

- High performance

- Used in games & system software

##### 🟩 JavaScript

- Runs in browsers

- Used for frontend & backend

---

## 2️⃣ Based on Programming Paradigm

A **paradigm** is a style of programming.

### A. Procedural Programming

- Step-by-step instructions

- Uses functions

- Focus on procedures

Example:

- C

### B. Object-Oriented Programming (OOP)

- Based on objects & classes

- Concepts: Encapsulation, Inheritance, Polymorphism, Abstraction

Examples:

- Java

- C++

### C. Functional Programming

- Uses pure functions

- Avoids changing state

- Focus on immutability

Examples:

- Haskell

- Scala

### D. Scripting Languages

- Used for automation

- Interpreted languages

Examples:

- Python

- PHP
