# 1️⃣ First-Class Functions

### 1.Definition

A programming language supports **first-class functions** if functions are treated like **normal variables**.

That means functions can:

- ✅ Be assigned to variables

- ✅ Be passed as arguments to other functions

- ✅ Be returned from functions

- ✅ Be stored in data structures (like arrays, lists)

---

### 2.Simple Real-Life Analogy

Think of a function like a **number**:

    int x = 10;

If functions are first-class, you can do something like:

    Function f = add;

---

### 3.Languages That Support First-Class Functions

- JavaScript

- Python

- Kotlin

- Scala

---

### 4.What About Java?

In early versions, Java did **not** support true first-class functions.

But from **Java 8**, Java introduced:

- Lambda expressions

- Functional interfaces

So now, Java supports **first-class behavior using objects**.

### Example (Java 8+)

#### Example 1:

    import java.util.function.Function;

    Function<Integer, Integer> square = x -> x * x;

    System.out.println(square.apply(5)); // 25

#### Example 2:

    import java.util.function.Function;

    public class Test {
        public static void main(String[] args) {
            Function<String, String> greet = name -> "Hello " + name;
            System.out.println(greet.apply("Jatin"));
        }
    }

Here:

- The lambda function is stored in a variable

- Passed around like data

> In Java, functions became first-class (almost) after Java 8 with lambda expressions.

#### Example 3: in JavaScript (Simple & Clear)

    //1. Assign function to variable

    const greet = function(name) {
        return "Hello " + name;
    };

    console.log(greet("Jatin"));

    //2. Pass function as argument

    function execute(fn) {
        console.log(fn("Patel"));
    }

    execute(greet);

---

### 5.Interview Angle

They may ask:

- Is Java a functional language?

- Does Java support first-class functions?

Answer:

> Java supports first-class functions **via lambda expressions and functional interfaces**, but internally they are objects.

### 6.Interview Definition

> First-class functions are functions that can be treated as values --- assigned, passed, and returned like any other variable.

# 2️⃣ Pure Functions

### 1.Definition

A **pure function** is a function that:

1.  Always produces the same output for the same input

2.  Has **no side effects**

---

### 2.What Are Side Effects?

- Modifying a global variable

- Printing to console

- Writing to file

- Updating database

- Changing object state

---

### 3.Impure Function Example

    int total = 0;

    int add(int x) {
        total += x; // modifies global state
        return total;
    }

Why impure?

- Depends on external variable `total`

- Changes program state

---

### 4.Pure Function Example

    public class Test {
        static int add(int a, int b) {
            return a + b;
        }

        public static void main(String[] args) {
            System.out.println(add(5, 3));
        }
    }

Why pure?

- Output depends only on inputs
- No state modification

✔ Same inputs → Same output\
✔ No external modification\
✔ No printing, no database calls, no global variable change

---

### 5.Functional Programming Languages (Focus on Purity)

- Haskell

- Erlang

These languages strongly enforce pure functions.

---

### 6.Why This Matters in DSA

When solving DSA problems:

#### Pure functions help with:

- Easier debugging

- Predictable recursion

- No hidden state bugs

- Easier unit testing

Example in recursion:

    int factorial(int n)
    {
        if (n == 0) return 1;
        return n \* factorial(n - 1);
    }

This is pure → perfect for DSA.

# Interview Trick Question

##### Q1: Are all first-class functions pure?

👉 ❌ No.

A function can be first-class but still impure.

Example:

    Function<Integer, Integer> f = x -> {
        System.out.println(x);  // side effect
        return x * 2;
    };

This is:

- First-class ✅
- Not pure ❌

##### Q2: Explain first-class function and Pure function.

👉
**First-class function:**

> A function that can be treated like a variable --- assigned, passed, and returned.

**Pure function:**

> A function that always returns the same output for the same input and has no side effects.
