# 3.Core Reasons Why OOP Exists

### 1.Encapsulation → Data Security

Encapsulation means:

> Binding data + methods together and hiding internal details.
> Data is hidden using private variables and accessed via methods.

Example in Java:

    class BankAccount {
        private double balance;

        public void deposit(double amount) {
            balance += amount;
        }

        public double getBalance() {
            return balance;
        }
    }

- ✔ No direct access to `balance` (Prevents unauthorized access)
- ✔ Controlled access
- ✔ Protects data (More secure)
- ✔ Improves security

Real example:

    Google protects internal system data using encapsulation principles.

---

### 2.Abstraction → Hide Complexity

👉 Show only essential features and hides internal logic..

User doesn't need to know internal logic.

Example:

- You use a car. (When you drive a car 🚗)

- You don't know how engine combustion works. (You don’t need to know how engine works internally.)

Example:

- ATM machine --- you use it without knowing internal code.

In programming:

    interface Vehicle {
        void start();
    }

    abstract class Shape {
        abstract void draw();
    }

You call `start()` --- internal logic is hidden.

- ✔ Reduces complexity
- ✔ Makes system easy to use
- ✔ Increases security

---

### 3.Inheritance → Code Reusability

👉 One class can inherit properties from another.

Create common logic once.

    class Animal {
        void eat() {
            System.out.println("Eating...");
        }
    }

    class Dog extends Animal {
        void bark() {
            System.out.println("Barking...");
        }
    }

- ✔ Dog reuses Animal features (Reuse existing code)
- ✔ Reduces duplication (Avoid duplication)

---

### 4️⃣ Polymorphism(Many Forms) → Flexibility

Same method, different behavior.

    class Animal {
        void sound() {

        }
    }

    class Dog extends Animal {
    void sound() {
            System.out.println("Bark");
        }
    }

- ✔ Flexible code
- ✔ Easy to extend

#### Example:

    class Calculator {

        int add(int a, int b) {
            return a + b;
        }

        double add(double a, double b) {
            return a + b;
        }
    }

- ✔ One method
- ✔ Many forms
