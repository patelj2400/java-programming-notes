## Static vs Dynamic Typing

---

## 1.What is Typing?

Typing means:

> **When and how a programming language checks the type of a variable.**

It answers:

- When is type checked?

- Can variable type change?

- Does compiler enforce types?

Example of type:

- `int`

- `String`

- `boolean`

- `float`

---

## 2.Static Typing

> Type checking happens **at compile time**.

#### Meaning:

You must declare the variable type before using it.

#### Example -- Java (Statically Typed)

Java is a Statically Typed Language.

That means:

> Type of a variable is checked at compile time.

    int number = 10;
    number = "Hello"; // ❌ Compile-time error

Compiler error occurs before program runs.

#### What Happens?

- Compiler knows `age` must store integer.

- It won't allow string assignment.

- Type safety is enforced early.

#### Advantages

- ✔ Types declared explicitly
- ✔ Type checking at compile time
- ✔ Errors caught early (compile-time)
- ✔ Better performance
- ✔ Better IDE support (autocomplete, refactoring)
- ✔ Safer for large systems

### Disadvantages

- ✖ More verbose
- ✖ Less flexible

### Example (Object Level)

    class Animal {

    }
    class Dog extends Animal {

    }

    Animal a = new Dog();  // ✅ Allowed
    Dog d = new Animal();  // ❌ Compile-time error

Java checks **type compatibility before execution**.

### Examples:

- C

- C++

- Java

- Go

- Rust

---

## 3.Dynamic Typing

> A **dynamically typed language** checks types **at runtime**.

That means:

- Variables are not bound to a single type

- Type errors appear while executing

- You don't declare the type explicitly.

---

#### Example -- Python (Dynamically Typed)

    number = 10
    number = "Hello" # ✅ No error at compile time

The variable changes type during execution.

---

#### ✅ Advantages

- ✔ Faster to write
- ✔ Flexible
- ✔ Great for scripting & rapid development

---

#### ❌ Disadvantages

- ✖ Errors found at runtime
- ✖ Harder to maintain large systems
- ✖ Refactoring is risky

### Examples:

- Python

- JavaScript

- Ruby

- PHP

---

## 5.Deep Interview Angle

##### ❓ Is Java purely statically typed?

Yes. Java checks types at compile time.

But...

👉 Java has **type inference**:

    var x = 10; // Java 10+

Still statically typed --- compiler infers the type.
But it supports runtime polymorphism.

---

##### ❓ Is Python weakly typed?

No.

Python is:

- Dynamically typed

- **Strongly typed**

Example:

    10 + "20" # ❌ TypeError

It does NOT automatically convert types.

---

##### ❓ What makes Java different from Python in typing?

Java:

- Type fixed at compile time

- Strict enforcement

Python:

- Type decided at runtime

- Variables can change type

---

## 6.Strong vs Weak Typing (Important Confusion)

| Concept           | Meaning                         |
| ----------------- | ------------------------------- |
| Static vs Dynamic | When type checking happens      |
| Strong vs Weak    | How strictly types are enforced |

Example:

- Java → Statically + Strongly typed

- Python → Dynamically + Strongly typed

- JavaScript → Dynamically + Weakly typed

Java is:

✔ Statically Typed\
✔ Strongly Typed

That means:

> You cannot mix types without explicit conversion.

    int x = 10;
    String y = "20";

    int result = x + y;  // ❌ Not allowed

## 7.Real Production Perspective

#### Large systems (Banking, Fintech, Enterprise)

Prefer → Static typing (Java)

Why?

- Fewer runtime crashes
- Prevents production bugs
- Better maintainability
- Helps refactoring safely
- Makes APIs predictable

#### Startups, AI, scripting

Prefer → Dynamic typing (Python)

Why?

- Faster prototyping

- Less boilerplate

- Rapid iteration

## Final Summary for Java

Java is:

- Statically typed
- Strongly typed
- Supports runtime polymorphism
- Supports type inference (var)
- Not dynamically typed

---

## Deep Technical Difference

#### Memory & Runtime Impact

- **Static typing** allows better memory layout planning and compiler optimizations.

- **Dynamic typing** requires runtime type metadata and type checking overhead.

Example:

- In Java, variable types are known before execution.

- In Python, every object carries type information at runtime.

---

### Final Summary (1-Line)

> Static typing = Safety & performance\
> Dynamic typing = Flexibility & speed
