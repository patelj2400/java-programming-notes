# Types of Classes in Java

In Java, classes can be categorized based on **structure, behavior, and usage**.

Java supports the following main types of classes:

1.  Normal (Concrete) Class

2.  Abstract Class

3.  Final Class

4.  Static Nested Class

5.  Inner Class

6.  Anonymous Class

7.  Enum Class

8.  Record Class (Java 14+)

---

## 1. Normal (Concrete) Class

👉 A regular class where we can create objects.

    class Student {
        String name;

        void study() {
            System.out.println("Studying...");
        }

    }

✔ Objects can be created
✔ Contains methods and variables

---

## 2 Abstract Class

- 👉 A class declared using `abstract` keyword.
- 👉 Cannot create objects directly.
- 👉 May contain abstract (unimplemented) methods.

##### Example:

    abstract class Animal {

        abstract void sound();  // abstract method

        void eat() {
            System.out.println("Animal is eating");
        }

    }

Child class must implement abstract methods:

    class Dog extends Animal {
        void sound() {
            System.out.println("Bark");
        }

    }

✔ Used for partial abstraction\
✔ Important in OOP & DSA design

---

## 3. Final Class

👉 A class declared using `final` keyword.
👉 Cannot be inherited.

    final class Vehicle {
        void run() {
            System.out.println("Running");
        }
    }

❌ Cannot extend this class.

Real example:

- String (Immutable class)

✔ Used for security & immutability

---

## 4. Static Nested Class

👉 A class defined inside another class using `static`.

    class Outer {

        static class Inner {
            void display() {
                System.out.println("Inside static nested class");
            }
        }

    }

Accessing it:

    Outer.Inner obj = new Outer.Inner();
    obj.display();

✔ Does not require outer class object
✔ Used for grouping related classes

---

## 5. Inner Class (Non-Static Nested Class)

👉 A class inside another class (without static).

    class Outer {

        class Inner {
            void show() {
                System.out.println("Inner class method");
            }
        }

    }

Accessing:

    Outer o = new Outer();
    Outer.Inner i = o.new Inner();
    i.show();

✔ Needs outer class object
✔ Used for logical grouping

---

## 6. Anonymous Class

👉 A class without a name.
👉 Used for one-time implementation.

    Runnable r = new Runnable() {
        public void run() {
            System.out.println("Running...");
        }
    };

    r.run();

✔ Used in event handling
✔ Common before Lambda expressions

---

## 7. Enum Class

👉 Used to define a fixed set of constants.

    enum Day {
        MONDAY, TUESDAY, WEDNESDAY
    }

✔ Type-safe constants
✔ Used in switch cases

---

## 8. Record Class (Java 14+)

👉 Introduced to reduce boilerplate code.
👉 Automatically creates constructor, getters, equals(), hashCode().

    record Person(String name, int age) {}

Usage:

    Person p = new Person("Jay", 22);
    System.out.println(p.name());

✔ Immutable data holder
✔ Useful in DTOs

---

# Quick Summary Table

| Type          | Object Creation | Inheritance | Use Case            |
| ------------- | --------------- | ----------- | ------------------- |
| Normal        | ✅ Yes          | ✅ Yes      | General purpose     |
| Abstract      | ❌ No           | ✅ Yes      | Partial abstraction |
| Final         | ✅ Yes          | ❌ No       | Security            |
| Static Nested | ✅ Yes          | ✅ Yes      | Grouping            |
| Inner         | ✅ Yes          | ✅ Yes      | Logical grouping    |
| Anonymous     | ✅ Yes          | Limited     | One-time use        |
| Enum          | ✅ Yes          | ❌ No       | Constants           |
| Record        | ✅ Yes          | ❌ Extends  | Data model          |

---

# 🔥 Important for DSA

When building:

- LinkedList → Normal Class

- Node → Inner Class

- Template structures → Abstract Class

- Constants → Enum
