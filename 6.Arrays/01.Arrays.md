# Arrays in Java (DSA Perspective)

---

## Why Do We Need Arrays?

##### Problem 1: Store one roll number

    int a = 19;

##### Problem 2: Store five roll numbers

Without arrays:

    int r1 = 23;
    int r2 = 55;
    int r3 = 9;
    int r4 = 18;
    int r5 = 12;

Now imagine storing **500 roll numbers** ❌\
Very repetitive.

#### ✅ Solution: Use Array

An array allows storing multiple values of the same type in one structure.

---

## 1. What is an Array?

An **array** is a collection of elements of the **same data type** stored in **contiguous memory locations**.

👉 Think of it like a row of boxes:

    Index: 0   1  2  3  4
    Value: 10 20 30 40 50

Each element is accessed using its **index** (starts from 0).

- All elements must be of the same type.
- Size must be specified.
- Index starts from 0.
- Arrays are objects in Java.

---

## 2. Why Use Arrays?

Why Use Arrays?

- Store multiple values in a single variable

- Easy access using index

- Improves code organization

Why Arrays Are Important in DSA?

Arrays are:

- Fast for accessing elements → **O(1)**

## 5. Memory Representation (Very Important for Interviews)

Java has:

- Stack Memory

- Heap Memory

##### Internal View

    Stack               Heap
    -----               -----------------
    arr -------------> [10][20][30][40][50]

##### Stack:

- Variable `arr` is a **reference** stored in stack

##### Heap:

- Actual array object `[0, 0, 0]`

##### Key Points:

- Array is an **object**
- Objects are stored in **Heap Memory**.
- Reference variables are stored in Stack.
- Memory is allocated at runtime.
- This is called **Dynamic Memory Allocation**.
- Length is fixed

##### Indexing in Arrays

Example:

    int[] arr = {3, 18, 9, 2};

Indexes:

| Index | Value |
| ----- | ----- |
| 0     | 3     |
| 1     | 18    |
| 2     | 9     |
| 3     | 2     |

- Default value of reference variables.

- Cannot assign null to primitive types.

## 9. Internal Working of Object Arrays

For:

    String[] arr = new String[3];

- Stack → arr reference

- Heap → array object

- Each index stores reference to String object

- Initially → null

## 10. Important Properties

| Feature                | Arrays     |
| ---------------------- | ---------- |
| Size                   | Fixed      |
| Memory                 | Contiguous |
| Access                 | O(1)       |
| Insert/Delete (middle) | O(n)       |
| Can grow?              | ❌ No      |

✔ Arrays are stored in **Heap memory**\
✔ Size is fixed after creation\
✔ Index out of range → `ArrayIndexOutOfBoundsException`\
✔ `.length` property gives size

## 11. 1D Array (Input and Output)

#### Input using for loop

    Scanner in = new Scanner(System.in);
    int[] arr = new int[5];

    for(int i = 0; i < arr.length; i++) {
        arr[i] = in.nextInt();
    }

#### Output Methods

##### 1. Normal for loop

    for(int i = 0; i < arr.length; i++) {
        System.out.println(arr[i]);
    }

##### 2. Enhanced For Loop (For-Each)

    for(int num : arr) {
        System.out.println(num);
    }

##### 3. Arrays.toString()

    System.out.println(Arrays.toString(arr));

Best and cleanest method.

##### 4. Array Index Out Of Bound

    System.out.println(arr[5]); // Error

If size is 5, max index is 4.

---

## 12. Passing Arrays in Functions

Example:

    static void change(int[] arr) {
        arr[0] = 99;
    }

Call:

    int[] nums = {3, 4, 5};

    change(nums);

Result:

    99 4 5

Why?

- Java is Call by Value.

- But for objects, copy of reference is passed.

- Both references point to same object.

- Arrays are mutable.

---

## 13. 2D Arrays

##### 1. Definition

    int[][] arr = new int[3][3];

Represents a matrix.

##### 2. Internal Structure

2D array = Array of arrays.

    arr →   [ ref ] [ ref ] [ ref ]
             ↓        ↓        ↓
            [1 2 3]  [4 5 6]  [7 8 9]

Each row is a separate array object.

##### 3. Column Size Not Mandatory

    int[][] arr = new int[3][];

Each row can have different size.

Example:

    int[][] arr = {
    {1,2,3},
    {4,5},
    {6,7,8,9}
    };

##### 4. Input in 2D Array

    for(int row = 0; row < arr.length; row++) {
        for(int col = 0; col < arr[row].length; col++) {
            arr[row][col] = in.nextInt();
        }
    }

---

##### 5. Output in 2D Array

    for(int row = 0; row < arr.length; row++)
    {
        for(int col = 0; col < arr[row].length; col++)
        {
            System.out.print(arr[row][col] + " ");
        }
        System.out.println();
    }

Or:

    System.out.println(Arrays.toString(arr[row]));

---

### Continuous Memory?

In C/C++ → Arrays are continuous.

In Java:

- Arrays are objects.

- Heap objects may not be continuous.

- Depends on JVM.
