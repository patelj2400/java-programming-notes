# Constants in Java

👉 **Constants** are just the opposite --- their values **cannot change once assigned**.

---

## 1. What is a Constant?

A **constant** is a variable whose value remains fixed throughout the program execution.

In Java, we use the `final` keyword to declare constants.

#### Syntax:

    final dataType CONSTANT_NAME = value;

---

## 2. Example of Constant in Java

    public class Example {
    public static void main(String[] args) {

            final double PI = 3.14159;

            System.out.println(PI);

            // PI = 3.14; ❌ Error (Cannot change value)
        }

    }

#### Explanation:

- `final` → makes the variable constant

- `double` → data type

- `PI` → constant name (by convention, written in uppercase)

- If you try to change `PI`, Java gives a **compile-time error**

---

## 3. Why Do We Use Constants?

#### ✔️ 1. Prevent Accidental Changes

If a value should never change (like π or tax rate), we make it constant.

#### ✔️ 2. Improves Code Readability

Instead of writing:

    double area = 3.14159 * r * r;

We write:

    final double PI = 3.14159;
    double area = PI * r * r;

More readable and meaningful 👍

#### ✔️ 3. Easy Maintenance

If value changes, update it in **one place only**.

Used for fixed values (PI, tax rate, limits, etc.)

---

## 4.Naming Convention for Constants

By convention:

- Use **UPPERCASE letters**

- Separate words with `_`

#### Examples:

    final int MAX_SIZE = 100;
    final double TAX_RATE = 0.18;
    final String COMPANY_NAME = "TechCorp";

---

## 5.Types of Constants in Java

#### 1.Local Constant

Declared inside a method.

    void calculate() {
        final int DAYS_IN_WEEK = 7;
    }

---

#### 2.Instance Constant

Declared inside a class but outside methods.

    class Example {
        final int MAX = 100;
    }

---

#### 3. Static Constant (Most Common)

Usually used for global constants.

    class MathUtils {
        public static final double PI = 3.14159;
    }

Accessed using:

    MathUtils.PI

👉 `static` → belongs to class\
👉 `final` → cannot change\
👉 Commonly used in utility classes

## 7.Important Rules

✔ Must be initialized when declared
✔ Cannot be reassigned
✔ `final` makes it constant
✔ Value fixed after assignment
✔ Primitive constant → value fixed
✔ Object reference final → reference fixed, but object data can change

#### Example:

    final List list = new ArrayList();
    list.add("Hello");   // Allowed
    list = new ArrayList(); // ❌ Not allowed

---

## 8.Constant vs Variable

| Feature      | Variable        | Constant               |
| ------------ | --------------- | ---------------------- |
| Can change?  | ✅ Yes          | ❌ No                  |
| Keyword      | none            | `final`                |
| Naming style | camelCase       | UPPER_CASE             |
| Example      | `int age = 20;` | `final int MAX = 100;` |

---

## 9.Difference between `const` (C/C++) and `final` (Java)

| Feature            | `const` (C/C++)                               | `final` (Java)                                  |
| ------------------ | --------------------------------------------- | ----------------------------------------------- |
| **Purpose**        | Makes variable read-only                      | Makes variable, method, or class non-modifiable |
| **For Variables**  | Value cannot be changed                       | Value cannot be reassigned                      |
| **For Objects**    | Object data can change (if members not const) | Reference cannot change, object data can change |
| **For Methods**    | ❌ Not applicable                             | Method cannot be overridden                     |
| **For Classes**    | ❌ Not applicable                             | Class cannot be inherited                       |
| **Initialization** | Can be initialized later (in C++)             | Must be initialized once                        |

#### Example

##### C++

    const int x = 10;
    x = 20; // ❌ Error

##### Java

    final int x = 10;
    x = 20; // ❌ Error

##### Key Interview Point

- `const` → Mainly for **data protection**

- `final` → Used for **variable, method, and class restriction**

---

## Quick Interview Points

- `final` keyword makes variable constant.

- `static final` is used for global constants.

- Constants improve readability and maintainability.

- Reassigning a constant gives **compile-time error**.
