# Variable Hiding vs Shadowing

Students often confuse these two. Let's separate them clearly.

---

## Variable Hiding

Happens between **parent and child classes**.

    class A {
        int x = 10;
    }

    class B extends A {
        int x = 20; // Hiding
    }

✔ Same variable name
✔ Inheritance involved
✔ Different classes

---

## Variable Shadowing

Happens inside the **same class or method** when a local variable hides an instance variable.

    class Test
    {
        int x = 10;

        void show()
        {
            int x = 20;   // Shadowing
            System.out.println(x);        // 20
            System.out.println(this.x);   // 10
        }
    }

✔ Same variable name
✔ Same class
✔ Local variable hides instance variable

---

## Key Difference Table

| Feature                    | Variable Hiding | Variable Shadowing |
| -------------------------- | --------------- | ------------------ |
| Happens Between            | Parent & Child  | Local & Instance   |
| Requires Inheritance       | ✅ Yes          | ❌ No              |
| Keyword to access original | `super`         | `this`             |
| Scope Type                 | Class-level     | Method-level       |

---

## Memory Diagram Explanation

### Case:

    class Parent {
        int x = 10;
    }

    class Child extends Parent {
        int x = 20;
    }

    Parent obj = new Child();

---

## What Happens in Memory?

#### Heap Memory (Object Created)

[ Child Object ]
[--------------- ]
Parent part:
x = 10

Child part:
x = 20

Both variables exist in memory.

---

#### Stack Memory (Reference)

Stack:
obj → points to Child object
Type of obj = Parent

---

## Why obj.x gives 10?

Because:

- Variable access depends on **reference type**

- Reference type = Parent

- So compiler binds to Parent.x

Even though object is Child.

---

## But if method overriding?

    class Parent {
        void show() { System.out.println("Parent"); }
    }

    class Child extends Parent {
        void show() { System.out.println("Child"); }
    }

    Parent obj = new Child();
    obj.show(); // Child

Because:

- Methods use **dynamic binding**

- Variables use **static binding**

---

## DSA-Level Understanding

In DSA problems:

- Arrays, objects, references matter a lot

- Always remember:

> 🔹 Variables → compile-time
> 🔹 Methods → runtime

That's why understanding reference type vs object type is critical.

---

## Final Interview One-Line Summary

- Static variable hiding → resolved at compile time using class reference

- Hiding → subclass variable hides superclass variable

- Shadowing → local variable hides instance variable

- Variables are never polymorphic
