## Environment Variables

---

## 1. What Are Environment Variables?

👉 **Environment Variables** are system-level variables that store configuration information.

They are:

- Key--value pairs

- Used by OS and programs

- Accessible globally

#### Example:

    JAVA_HOME = C:\Program Files\Java\jdk-21\
    PATH = C:\Windows\System32;C:\Program Files\Java\jdk-21\bin

---

## 2. Why Are Environment Variables Needed?

They help programs:

- Locate executables (like `java`, `javac`)
- Store system configuration
- Pass runtime configuration
- Allow running Java from command line
- Avoid hardcoding paths
- Help configure build tools
- Configure applications (Used by IDEs (like IntelliJ IDEA, Eclipse))
- Keep sensitive data (improve security) (like passwords, API keys)

Without setting `PATH`, you must run:

    C:\Program Files\Java\jdk-21\bin\javac Hello.java

After setting `PATH`, you can simply run:

    javac Hello.java

---

## 3. Important Java Environment Variables

#### 1. JAVA_HOME

👉 Points to JDK installation folder.

- Stores the path of the installed JDK.
- Many tools like Apache Maven, Gradle, and Apache Tomcat use this variable.

Example:

    JAVA_HOME = C:\Program Files\Java\jdk-21

Used by:

- Maven

- Gradle

- Tomcat

- IDEs

---

#### 2. PATH

👉 Tells OS where to find executable files.

You add:

    %JAVA_HOME%\bin

So system can find:

- `java`

- `javac`

- `jar`

---

#### 3. CLASSPATH

👉 Tells JVM where to find `.class` files.

- Contains directories where executable files are located.
- Required to run `java` and `javac` from anywhere in the command prompt.

Default:

    Current directory (.)

Example:

    CLASSPATH=.;C:\myLibraries\myJar.jar

---

## 4. How Environment Variables Work Internally

When you run:

    javac Hello.java

OS:

1.  Looks inside `PATH`

2.  Finds `javac.exe`

3.  Executes it

If not found → "command not recognized" error.

---

## 5. How Java Accesses Environment Variables

In Java:

    System.getenv("JAVA_HOME");

Example:

    public class Test {
        public static void main(String[] args) {
            System.out.println(System.getenv("JAVA_HOME"));
        }
    }

---

## 6. Environment Variables vs System Properties

| Feature   | Environment Variable | System Property      |
| --------- | -------------------- | -------------------- |
| Level     | OS level             | JVM level            |
| Access    | System.getenv()      | System.getProperty() |
| Example   | JAVA_HOME            | java.version         |
| Set using | OS settings          | -Dkey=value          |

Example:

    java -Denv=prod Test

Access:

    System.getProperty("env");

---

## 7. How to Set Environment Variables (Windows)

1.  Search "Environment Variables"

2.  Click **Edit system environment variables**

3.  Click **Environment Variables**

4.  Add:
    - JAVA_HOME

    - Edit PATH → Add `%JAVA_HOME%\bin`

---

## 8. How to Set (Mac/Linux)

Open terminal:

    export JAVA_HOME=/usr/lib/jvm/jdk-21\
    export PATH=$JAVA_HOME/bin:$PATH

Add in:

- `~/.bashrc`

- `~/.zshrc`

## ✔ Difference between `PATH` and `JAVA_HOME`

| `PATH`                                           | `JAVA_HOME`                         |
| ------------------------------------------------ | ----------------------------------- |
| Stores locations of executable files             | Stores location of JDK installation |
| Used by OS to find commands like `java`, `javac` | Used by tools to locate Java        |
| Contains many paths                              | Contains only JDK root path         |

### Example:

    JAVA_HOME = C:\Program Files\Java\jdk-21\
    PATH = %JAVA_HOME%\bin

👉 `PATH` helps run Java
👉 `JAVA_HOME` tells where Java is installed

Tools like Apache Maven and Gradle use `JAVA_HOME`.

---

## ✔ Why we add `bin` folder to `PATH`

Because:

- `bin` contains executable files like:
  - `java`

  - `javac`

  - `jar`

If `bin` is not added to `PATH`:

    'java' is not recognized as an internal or external command

👉 Adding `%JAVA_HOME%\bin` allows running Java from any directory.

---

## ✔ How to access environment variables in Java

Use `System.getenv()` method.

### Example:

    class Test {
        public static void main(String[] args) {
            String value = System.getenv("JAVA_HOME");
            System.out.println(value);
        }
    }

To get all environment variables:

    System.getenv();

---

### Interview Tip

- Environment variables → `System.getenv()`

- System properties → `System.getProperty()`
