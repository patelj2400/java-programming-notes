# Operators in Java

In Java, **operators** are special symbols used to perform operations on variables and values.

Example:

    int a = 10;
    int b = 5;
    int sum = a + b; // + is an operator

Java operators are mainly divided into the following types:

---

### 1.Arithmetic Operators

> Used for mathematical calculations.

| Operator | Name                | Description                      | Example |
| -------- | ------------------- | -------------------------------- | ------- |
| `+`      | Addition            | Adds together two values         | `a + b` |
| `-`      | Subtraction         | Subtracts one value from another | `a - b` |
| `*`      | Multiplication      | Multiplies two values            | `a * b` |
| `/`      | Division            | Divides one value by another     | `a / b` |
| `%`      | Modulus (remainder) | Returns the division remainder   | `a % b` |

#### Example:

    int a = 10, b = 3;

    System.out.println(a + b); // 13
    System.out.println(a - b); // 7
    System.out.println(a * b); // 30
    System.out.println(a / b); // 3
    System.out.println(a % b); // 1

#### Increment & Decrement

| Operator | Name      | Meaning       |
| -------- | --------- | ------------- |
| `++`     | Increment | Increase by 1 |
| `--`     | Decrement | Decrease by 1 |

#### Example:

    int x = 5;
    x++; // 6
    x--; // 5

---

### 2.Relational (Comparison) Operators

> Used to compare two values.
> They return **boolean (true/false)**.

| Operator | Meaning               | Example |
| -------- | --------------------- | ------- |
| `==`     | Equal to              | x == y  |
| `!=`     | Not equal             | x != y  |
| `>`      | Greater than          | x > y   |
| `<`      | Less than             | x < y   |
| `>=`     | Greater than or equal | x >= y  |
| `<=`     | Less than or equal    | x <= y  |

#### Example:

    int a = 10, b = 5;

    System.out.println(a > b); // true
    System.out.println(a == b); // false

---

### 3.Logical Operators

> Used with boolean values.

Logical or ( || )

| Operator | Meaning     | Description                                             |
| -------- | ----------- | ------------------------------------------------------- |
| `&&`     | Logical AND | Returns true if both statements are true                |
|          | Logical or  | Returns true if one of the statements is true           |
| `!`      | Logical NOT | Reverse the result, returns false if the result is true |

    boolean a = true;
    boolean b = false;

    System.out.println(a && b); // false
    System.out.println(a || b); // true
    System.out.println(!a); // false

---

### 4.Assignment Operators

> Used to assign values.

| Operator | Example   | Meaning    |
| -------- | --------- | ---------- |
| `=`      | `a = 5`   | x = 5      |
| `+=`     | `a += 2`  | a = a + 2  |
| `-=`     | `a -= 2`  | a = a - 2  |
| `*=`     | `a *= 2`  | a = a \* 2 |
| `/=`     | `a /= 2`  | a = a / 2  |
| `%=`     | `a %= 2`  | a = a % 2  |
| &=       | `a &= 3`  | a = a & 3  |
| OR =     | `a OR= 3` | a = a OR 3 |
| ^=       | `a^= 3`   | a = a^ 3   |
| >>=      | `a >>= 3` | a = a>> 3  |
| <<=      | `a <<= 3` | a = a<< 3  |

---

### 5.Unary Operators

> Operate on a single operand.

| Operator | Meaning            |
| -------- | ------------------ |
| `+`      | Positive           |
| `-`      | Negative           |
| `++`     | Increment          |
| `--`     | Decrement          |
| `!`      | Logical complement |

---

## 6.Bitwise Operators (Advanced)

> Work on binary values.

| Operator | Meaning     |
| -------- | ----------- |
| `&`      | AND         |
| OR       | OR          |
| `^`      | XOR         |
| `~`      | NOT         |
| `<<`     | Left shift  |
| `>>`     | Right shift |

> OR = |

Example:

    int a = 5; // 0101
    int b = 3; // 0011

    System.out.println(a & b); // 1
    System.out.println(a | b); // 7

---

## 7.Ternary Operator

Short form of `if-else`.

Syntax:

    condition ? value_if_true : value_if_false;

Example:

    int age = 18;
    String result = (age >= 18) ? "Adult" : "Minor";

---

### 8. instanceof Operator

Checks whether an object belongs to a class.

    if (obj instanceof String)

---

## Order of Operations

Here are some common operators, from highest to lowest priority:

- `()` - Parentheses
- `*`, `/`, `%` - Multiplication, Division, Modulus
- `+`, `-` - Addition, Subtraction
- `>`, `<`, `>=`, `<=` - Comparison
- `==`, `!=` - Equality
- `&&` - Logical AND
- `||` - Logical OR
- `=` - Assignment

# Important Interview Points

##### Q1. == operator

👉 For primitives → compares actual values.
👉 For objects → compares memory references (addresses).

##### Q2. && operator (Logical AND)

👉 Short-circuit operator.
If first condition is false, second condition is not checked.

##### Q3. Difference between prefix ++x and postfix x++.

👉 ++x → Increment first, then use value.
👉 x++ → Use value first, then increment.

##### Q4. Integer division removes decimal part.

👉 Removes decimal part (no rounding).
Example: 5 / 2 = 2

##### Q5. Bitwise Operators in DSA

👉 Used for masking, toggling bits, checking even/odd, swapping numbers, fast calculations (e.g., x & 1).

---

## Operator Precedence & Associativity (Very Important for Interviews)

👉 **Operator Precedence** = Priority of operators (which executes first).\
Example:\
`2 + 3 * 4` → `*` runs first → Answer = `14`

👉 **Associativity** = Direction of evaluation when precedence is same.

- Most operators → **Left to Right**

- Assignment (`=`), Unary (`++`, `--`) → **Right to Left**

Example:\
`int x = 5 - 3 + 2;` → Left to Right → Answer = `4`

---

## Difference Between `&` and `&&`

| `&` (Single AND)                      | `&&` (Logical AND)                |
| ------------------------------------- | --------------------------------- |
| Bitwise AND (also works with boolean) | Logical AND                       |
| **Does NOT short-circuit**            | **Short-circuits**                |
| Always evaluates both sides           | Stops if first condition is false |
| Used in bit manipulation              | Used in conditions                |

Example:

    false & someMethod(); // someMethod() executes
    false && someMethod(); // someMethod() NOT executed
