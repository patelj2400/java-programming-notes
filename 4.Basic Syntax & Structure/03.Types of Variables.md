# Types of Variables

In Java, variables are classified based on **where they are declared** and **how long they live in memory**.

There are **3 main types of variables** in Java:

---

## 1.Local Variables

- Declared **inside a method, constructor, or block**

#### Characteristics:

- Scope → Only inside that method/block
- Stored in → **Stack memory**
- Lifetime → Till method execution
- Must be initialized before use
- No default values
- Created when method starts, destroyed when method ends

#### Example:

    class Test {
        void display() {
            int x = 10; // Local variable
            System.out.println(x);
        }
    }

#### DSA Insight:

Loop counters (`i`, `j`), temporary variables in algorithms are usually **local variables**.

#### Interview Line:

> Local variables exist only during method execution and are stored in stack memory.

---

## 2.Instance Variables (Non-Static Variables)

- Declared **inside a class but outside methods, without static**
- Belong to **object**

#### Characteristics:

- Stored in → **Heap memory**
- Each object gets its own copy
- Have default values (Gets default values (0, null, false, etc.))
- Accessed using object reference
- Lifetime → As long as object exists

#### Example:

    class Student {
    int rollNo; // Instance variable
    String name;

        void show() {
            System.out.println(rollNo + " " + name);
        }

    }

#### Access

    Student s1 = new Student();
    s1.rollNo = 101;

#### DSA Insight:

When designing classes like:

- `Node` in Linked List

- `TreeNode` in Binary Tree

  Their data members are **instance variables**.

#### Interview Line:

> Instance variables are object-level variables stored in heap memory.

---

## 3.Static Variables (Class Variables)

- Declared using `static` keyword
- Belong to **class**, not object

#### Characteristics:

- Only **one copy per class**
- Stored in → **Method Area (Class Area)**
- Shared among all objects
- Access using `ClassName.variableName`
- Loaded when class is loaded

#### Example:

    class Student {
        static String college = "IIT"; // Static variable
        int rollNo;
    }

#### Access

    System.out.println(Student.college);

#### DSA Insight:

Used for:

- Counting objects

- Constants

- Shared configuration

#### Interview Line:

> Static variables are class-level variables shared among all objects.

---

## Quick Comparison Table

| Feature       | Local            | Instance        | Static                  |
| ------------- | ---------------- | --------------- | ----------------------- |
| Declared      | Inside method    | Inside class    | Inside class (`static`) |
| Belongs to    | Method           | Object          | Class                   |
| Memory        | Stack            | Heap            | Method Area             |
| Default Value | ❌ No            | ✅ Yes          | ✅ Yes                  |
| Shared?       | ❌               | ❌              | ✅                      |
| Lifetime      | Method execution | Object lifetime | Class lifetime          |

## Interview Twist Questions

##### Q1: Why can't local variables be `static`?

👉 Because static belongs to class level, but local variables belong to method/block scope.
Local variables:

- Are created when method is called

- Stored in **stack memory**

- Destroyed after method execution

`static` variables:

- Exist once per class

- Stored at **class level**, not inside a method

So Java does not allow `static` inside methods.

##### Q2: Can we access instance variables inside static methods? (Tricky 😎)

👉 No, directly we cannot.

Because:

- Static methods belong to **class**

- Instance variables belong to **object**

But we **can access them using an object reference**:

    class Test {
        int x = 10;

        static void show()
        {
            Test obj = new Test();
            System.out.println(obj.x); // Allowed
        }
    }

So the rule:

> Static method cannot access instance members directly, but can access them through an object.

##### Q3: Where exactly are static variables stored in JVM memory?

👉 Static variables are stored in the Method Area of JVM.

In modern JVM implementations like **HotSpot JVM**, static variables are stored in **Metaspace** (which replaced PermGen after Java 8).

Memory structure simplified:

- Stack → Local variables

- Heap → Objects

- Method Area / Metaspace → Class metadata + Static variables

##### Q4:Why can't local variables have access modifiers?

👉 Because they exist only inside a method --- access modifiers control visibility between classes.

##### Q5:Why must local variables be initialized?

👉 Because JVM does not assign default values to stack memory variables.

##### Q6:Where are static variables stored in JVM?

👉 In the **Method Area** of the JVM.
