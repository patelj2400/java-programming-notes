# Primitive Data Types in Java

In Java, **primitive data types** are the most basic types of data.
They store **simple values directly in memory** (not objects).

Java has **8 primitive data types**.

## 1.Integer Types (Whole Numbers)

#### 1. `byte`

- Size: **1 byte (8 bits)**
- Range: **-128 to 127**
- Default value: `0`

Example:

    byte age = 25;

👉 Used when saving memory in large arrays.

---

#### 2. `short`

- Size: **2 bytes (16 bits)**
- Range: **-32,768 to 32,767**
- Default value: `0`

Example:

    short year = 2025;

---

#### 3. `int` ✅ (Most Common)

- Size: **4 bytes (32 bits)**
- Range: **-2^31 to 2^31 - 1**
- Default value: `0`

Example:

    int salary = 50000;

👉 Most commonly used for integers.

---

#### 4. `long`

- Size: **8 bytes (64 bits)**
- Range: **-2^63 to 2^63 - 1**
- Default value: `0L`

Example:

    long population = 14000000000L; // L is required

👉 Used for very large numbers.

---

## 2.Floating Point Types (Decimal Numbers)

#### 5. `float`

- Size: **4 bytes (32 bits)**
- Precision: ~6-7 decimal digits
- Default value: `0.0f`

Example:

    float price = 99.99f; // f is required

---

#### 6. `double` ✅ (Most Common)

- Size: **8 bytes (64 bits)**
- Precision: ~15 decimal digits
- Default value: `0.0d`

Example:

    double pi = 3.14159265359;

👉 Default decimal type in Java.

---

## 3.Character Type

#### 7. `char`

- Size: **2 bytes (16 bits)**
- Stores: **Single Unicode character** (Unicode (UTF-16).)
- Range: `'\u0000'` to `'\uffff'`
- Default value: `'\u0000'`

Example:

    char grade = 'A';

👉 Stores characters using Unicode.

---

## 4.Boolean Type

### 8. `boolean`

- Size: JVM dependent (not precisely defined)
- Values: `true` or `false`
- Default value: `false`

Example:

    boolean isJavaFun = true;

👉 Used in conditions and decision-making.

---

---

## Key Characteristics

- Stored in **Stack memory** (for local variables).

- Faster than objects.

- Cannot call methods.

- Have default values when declared as class variables:

| Type    | Default Value |
| ------- | ------------- |
| byte    | 0             |
| short   | 0             |
| int     | 0             |
| long    | 0L            |
| float   | 0.0f          |
| double  | 0.0d          |
| char    | '\u0000'      |
| boolean | false         |

---

## Important Interview Points

1.  ✔ `int` is default integer type

2.  ✔ `double` is default decimal type

3.  ✔ `float` requires `f` suffix

4.  ✔ `long` requires `L` suffix for large numbers

5.  ✔ `char` uses **Unicode (2 bytes)**

6.  ✔ Primitive types are stored in **stack memory (generally)**

## Interview Question

##### Q1: Why Java has primitive types?

👉 To improve performance and reduce memory overhead compared to objects.
