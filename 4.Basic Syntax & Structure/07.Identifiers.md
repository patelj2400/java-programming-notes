## Java Identifiers

In Java, **identifiers** are the names given to program elements like:

- Variables

- Methods

- Classes

- Interfaces

- Packages

They help us identify different components in a program.

---

## 1.What is an Identifier?

An **identifier** is simply a name used to identify a variable, method, class, or other element in a Java program.

#### Example:

    int age = 25;

Here:

- `age` → Identifier (variable name)

class Student {

}

- `Student` → Identifier (class name)

---

## 2.Rules for Naming Identifiers in Java

Java has strict rules for naming identifiers:

### ✅ Allowed:

1.  Can contain:
    - Letters (A--Z, a--z)
    - Digits (0--9)
    - Underscore (\_)
    - Dollar sign ($)
2.  Must NOT start with a digit.
3.  Cannot use Java keywords.
4.  Case-sensitive (age and Age are different).
5.  No special symbols allowed

---

#### ✔ Valid Identifiers

    int number;
    int _count;
    int $price;
    int student1;
    int totalMarks;

---

#### ❌ Invalid Identifiers

    int 1number; // starts with digit
    int total-marks; // hyphen not allowed
    int class; // keyword
    int @value; // special character not allowed

---

## 3.Java Keywords (Cannot Be Used as Identifiers)

Some common Java keywords:

`int`, `class`, `public`, `static`, `void`, `if`, `else`, `for`, `while`, `return`

Example (Invalid):

    int class = 10; // ❌ Error

---

## 4.Case Sensitivity in Java

Java is **case-sensitive**.

    int age = 20;
    int Age = 30;

Both are different variables.

---

## 5.Naming Conventions (Best Practices)

These are not rules, but recommended standards.

#### Variable Name

✔ Use **camelCase**

    int totalMarks;
    String studentName;

#### Method Name

✔ Also camelCase

    calculateSum();
    getName();

#### Class Name

✔ Use **PascalCase**

    class StudentDetails
    class BankAccount

#### Constants

✔ Use UPPER_CASE

    final double PI = 3.14;

---

## 6.Special Identifiers

### `_` (underscore)

From Java 9 onwards, `_` alone cannot be used as an identifier.

    int \_ = 5; // ❌ Error in Java 9+

### `$`

Allowed but mostly used internally by JVM.

---

## 7.Real Example Program

    public class StudentData {

        static int totalStudents = 100;

        public static void main(String[] args) {

            int studentAge = 20;
            String studentName = "Rahul";

            System.out.println(studentName + " is " + studentAge + " years old.");
        }

    }

Identifiers used here:

- `StudentData`

- `totalStudents`

- `main`

- `args`

- `studentAge`

- `studentName`
