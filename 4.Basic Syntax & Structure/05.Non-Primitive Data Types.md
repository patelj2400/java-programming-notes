## Non-Primitive Data Types in Java

In Java, **Non-Primitive (Reference) Data Types** are data types that store **references (addresses)** of objects instead of actual values.

Unlike primitive types (`int`, `char`, `boolean`, etc.),

Non-primitive types:

- Are **created by the programmer** (except `String`, which is built-in)

- Can store **multiple values**

- Have **methods and properties**

- Are stored in **Heap memory**

- Default value = `null`

---

## 1. Class

A class is a blueprint to create objects.

    class Student {
        String name;
        int age;
    }

    Student s1 = new Student();

✔ Stored in **Heap memory**\
✔ Default value = `null`

Examples:

- `String`

- `Scanner`

- User-defined classes

---

## 2. Object

An object is an instance of a class.

    Student s1 = new Student();

Here:

- `Student` → class

- `s1` → reference variable

- `new Student()` → object

## 3.Arrays

![https://logicmojo.com/assets/dist/new_pages/images/arraymemoryjava.png](https://logicmojo.com/assets/dist/new_pages/images/arraymemoryjava.png)

#### What is an Array?

An **array** stores multiple values of the same type in a single variable.

    int[] numbers = {10, 20, 30};

#### Memory Understanding

- Array object stored in **Heap**
- `numbers` variable stores reference in **Stack**
- Array is an object in Java
- Fixed size

#### Accessing Elements

    numbers[0]; // 10
    numbers.length; // 3

#### Types of Arrays

- Single-dimensional

- Multi-dimensional

---

## 4. String

#### What is String?

A **String** is a sequence of characters.

String is a class in Java (not primitive).

    String name = "Jay";

Here:

- `"Jay"` is stored in **String Pool ((special heap area))**

- `name` stores the **reference** to that object

#### Important Points

- Strings are **immutable**

- Stored in **Heap (String Pool)**

- Belongs to `java.lang` package (auto imported)

#### Common Methods

    name.length();
    name.toUpperCase();
    name.charAt(0);
    name.equals("Jay");

## 5.Interfaces

#### What is an Interface?

An interface defines **what a class must do**, not how.

> Used to achieve abstraction and multiple inheritance.

interface:

    interface Animal {
        void sound();
    }

Class:

    class Dog implements Animal
    {
        public void sound()
        {
            System.out.println("Bark");
        }
    }

Classes implement interfaces.

## Memory Comparison (Primitive vs Non-Primitive)

| Feature       | Primitive    | Non-Primitive       |
| ------------- | ------------ | ------------------- |
| Stores        | Actual value | Reference (address) |
| Memory        | Stack        | Heap                |
| Methods       | ❌           | ✅                  |
| Size          | Fixed        | Depends on object   |
| Default value | 0 / false    | null                |
| Example       | int, char    | String, Array       |

## Interview Important Points

##### Q1: String is a class but behaves like primitive

👉 For that reason:

- `String` is a class in Java (`java.lang.String`).

- It behaves like primitive because:
  - It doesn't need `new` keyword (`String s = "Hello";`)

  - It is immutable.

  - It has special memory handling (String Pool).

That's why it _feels_ like primitive but technically it's an object.

##### Q2:All non-primitive types are passed by reference value

👉 Java is **pass-by-value only**.

- For primitives → value is copied.

- For objects → **reference is copied**, not the actual object.

So method gets a copy of the reference pointing to the same object.

Example idea:

- You can change object data inside method.

- But you cannot make original reference point to a new object.

##### Q3:Objects are stored in Heap

👉 Here:

- All objects (including `String`, arrays, custom classes) are created in **Heap memory**.

- Reference variables are stored in **Stack memory** (if local).

##### Q4: Default value of reference type is `null`

👉 If a reference variable is:

- Instance variable → default value = `null`

- Static variable → default value = `null`

- Local variable → ❌ no default value (must initialize manually)
