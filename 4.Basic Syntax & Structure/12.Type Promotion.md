# Type Promotion Rules

Type promotion happens in:

- Arithmetic operations

- Expressions

- Method calls

---

## Rule 1: byte, short, char → promoted to int

    byte a = 10;
    byte b = 20;
    int result = a + b; // NOT byte

Even though both are byte → result is int.

❌ This will give error:

    byte c = a + b; // Compilation error

✔ Correct way:

    byte c = (byte)(a + b);

---

## Rule 2: If one operand is larger type → result becomes larger type

    int a = 10;
    double b = 5.5;

    double result = a + b; // int → double

✔ Result is double

---

## Rule 3: Entire expression promoted to highest data type

    int a = 10;
    long b = 20L;
    float c = 5.5f;

    float result = a + b + c;

Promotion flow:

    int → long → float

Final type = float

---

## Rule 4: Constant expressions behave differently

    byte b = 10 + 20; // No error

Why?

Because compiler calculates at compile-time → result fits in byte.

But:

    byte x = 10;
    byte y = 20;
    byte z = x + y; // ERROR

Because variables are promoted to int.

---

## Type Promotion in DSA Problems

Very important for:

### 🔸 Prefix Sum

    int sum = 0;

    for(int i = 0; i < n; i++) {
        sum += arr[i];
    }

If array values large → use long

    long sum = 0;

Otherwise overflow occurs.

---

### 🔸 Multiplication Overflow

    int a = 100000;
    int b = 100000;

    long result = a * b; // ❌ Overflow first, then assigned

Correct way:

    long result = (long)a \* b;

Always cast before multiplication.

## Interview Trap Questions

#### Q: What is output?

    System.out.println(5 / 2);

✔ Output: 2

(int division)

---

    System.out.println(5 / 2.0);

✔ Output: 2.5\
(double promotion)

---

#### Q: What is type of this expression?

    'a' + 1

✔ int (because char → int)

## Summary Table

| Scenario       | Result Type |
| -------------- | ----------- |
| byte + byte    | int         |
| short + short  | int         |
| char + char    | int         |
| int + long     | long        |
| long + float   | float       |
| float + double | double      |

---

## Final DSA Advice

When solving problems:

✔ Use `long` for sums
✔ Cast before multiplication
✔ Remember small types become `int`
✔ Be careful with division
