## Unicode Support in Java

When we talk about **Unicode Support**, we mean the ability of a programming language to represent and process characters from **all human languages**, not just English.

---

# 1. What is Unicode?

Unicode is a **universal character encoding standard** that assigns a unique number (called a _code point_) to every character.

Examples:

| Character | Unicode Code Point |
| --------- | ------------------ |
| A         | U+0041             |
| a         | U+0061             |
| 1         | U+0031             |
| ₹         | U+20B9             |
| 中        | U+4E2D             |

👉 Unicode ensures that characters from Hindi, Chinese, Arabic, English, etc., are all supported.

---

# 2.Why Unicode is Important?

Before Unicode, computers used:

- **ASCII** American Standard Code for Information Interchange (only 128 characters)

- Could represent only English letters, digits, symbols

Problem:

- Cannot represent Hindi, Gujarati, Chinese, etc.

Unicode solves this by supporting **1,000,000+ characters**.

---

# 3.Unicode in Java

Java was designed with **Unicode support from the beginning**.

Java uses:

- **UTF-16 encoding**

- `char` = 2 bytes (16 bits)

- `String` = sequence of Unicode characters

---

## 4.How `char` Stores Unicode

In Java:

    char ch = 'A';
    char rupee = '₹';
    char hindi = 'अ';

Each character is internally stored using a **Unicode code value**.

You can also write characters using Unicode escape:

    char ch = '\u0041'; // 'A'
    char rupee = '\u20B9'; // ₹

---

# 5.Unicode Escape Sequence

Java supports Unicode escape sequence:

    \uXXXX

Where:

- `XXXX` = 4 hexadecimal digits

Example:

    public class Main {
        public static void main(String[] args) {
            System.out.println("\u0041"); // A
            System.out.println("\u0915"); // क
        }
    }

---

    public class Main {

                System.out.println(english);

Java supports all of these because of Unicode.

# 7. How It Relates to Memory (Important for DSA)

Since:

- `char` = 2 bytes
- `String` = array of `char`

Memory matters when:

- Working with large strings

- Solving DSA problems like:
  - String compression
  - Palindrome
  - Pattern matching

---

# 8. Difference: ASCII vs Unicode

| Feature          | ASCII                 | Unicode       |
| ---------------- | --------------------- | ------------- |
| Characters       | 128                   | 1M+           |
| Language Support | English only          | All languages |
| Size             | 1 byte                | 2+ bytes      |
| Used in Java?    | Internally compatible | YES (primary) |

---

# 9. Important Interview Concepts

✅ Java source code is written in Unicode\
✅ `char` supports Unicode\
✅ Java internally uses UTF-16\
✅ Escape sequence: `\uXXXX`\
✅ Unicode characters can affect string length (`length()` vs actual visible characters)

Example:

    String s = "😊";
    System.out.println(s.length()); // 2 (because emoji uses surrogate pair)

⚠️ Some Unicode characters (like emojis) use **2 char values** (surrogate pairs).
