# Java Math

In Java, mathematical operations are handled mainly using:

- **Arithmetic Operators** (`+ - * / %`)

- The **Math class** (for advanced mathematical functions)

It provides mathematical functions like power, square root, rounding, trigonometry, etc.

👉 All methods are static, so no object creation needed.

---

## 1. Arithmetic Operators (Basic Math)

These are built into Java.

| Operator | Meaning             | Example  | Output |
| -------- | ------------------- | -------- | ------ |
| `+`      | Addition            | `5 + 3`  | 8      |
| `-`      | Subtraction         | `5 - 3`  | 2      |
| `*`      | Multiplication      | `5 * 3`  | 15     |
| `/`      | Division            | `10 / 2` | 5      |
| `%`      | Modulus (remainder) | `10 % 3` | 1      |

### Example:

    public class Main {
    public static void main(String[] args) {
    int a = 10;
    int b = 3;
            System.out.println(a + b);  // 13
            System.out.println(a - b);  // 7
            System.out.println(a * b);  // 30
            System.out.println(a / b);  // 3
            System.out.println(a % b);  // 1
        }
    }

⚠️ Important:
`10 / 3 = 3` because both are integers (decimal part removed).
Use `double` for decimal result.

---

## 2.Math Class in Java

Java provides a built-in class called:

### `Math` class (java.lang package)

You don't need to import it.

It contains **static methods**, so we use:

    Math.methodName()

---

## 3.Common Math Methods

### 1. Absolute Value

    Math.abs(-10); // 10

---

### 2. Maximum & Minimum

    Math.max(10, 20); // 20
    Math.min(10, 20); // 10

---

### 3. Square Root

    Math.sqrt(25); // 5.0

---

### 4. Power (Exponent)

    Math.pow(2, 3); // 8.0

    (2³ = 8)

---

### 5. Rounding Numbers

    Math.round(4.6); // 5
    Math.floor(4.6); // 4.0
    Math.ceil(4.2); // 5.0

| Method    | Meaning         |
| --------- | --------------- |
| `round()` | Closest integer |
| `floor()` | Round down      |
| `ceil()`  | Round up        |

---

### 6. Random Numbers

    Math.random(); // 0.0 to 1.0

    To get 1--10:

    int num = (int)(Math.random() \* 10) + 1;

---

## 4.Complete Example

    public class Main {
    public static void main(String[] args) {
    int a = -5;
    int b = 10;

            System.out.println("Absolute: " + Math.abs(a));
            System.out.println("Maximum: " + Math.max(a, b));
            System.out.println("Square Root: " + Math.sqrt(16));
            System.out.println("Power: " + Math.pow(2, 4));
            System.out.println("Random: " + Math.random());
        }

    }

---

## 5.Important Notes for DSA

- `%` operator → used in cyclic problems

- `Math.max()` / `Math.min()` → used in optimization problems

- `Math.pow()` → avoid in performance-critical loops (use multiplication instead)

- `Math.sqrt()` → used in prime number checking

- `Math.abs()` → useful in distance problems

## Common Math Methods

| Method          | Description              | Example                   |
| --------------- | ------------------------ | ------------------------- |
| `Math.sqrt(x)`  | Square root              | `Math.sqrt(25)` → `5.0`   |
| `Math.pow(a,b)` | a raised to power b      | `Math.pow(2,3)` → `8.0`   |
| `Math.abs(x)`   | Absolute value           | `Math.abs(-10)` → `10`    |
| `Math.max(a,b)` | Maximum value            | `Math.max(5,9)` → `9`     |
| `Math.min(a,b)` | Minimum value            | `Math.min(5,9)` → `5`     |
| `Math.round(x)` | Round to nearest int     | `Math.round(4.6)` → `5`   |
| `Math.ceil(x)`  | Round up                 | `Math.ceil(4.1)` → `5.0`  |
| `Math.floor(x)` | Round down               | `Math.floor(4.9)` → `4.0` |
| `Math.random()` | Random number (0.0--1.0) | `Math.random()`           |

### Important Interview Points

- `Math` class is **final** (cannot be extended).

- Constructor is **private** (cannot create object).

- All methods are **static**.

- Uses `double` for most calculations.
