# Static Variable Hiding

Static variables belong to the **class**, not the object.

When a subclass declares a static variable with the same name as its superclass → it **hides** the parent's static variable.

---

## Example

    class Parent {
        static int x = 10;
    }

    class Child extends Parent {
        static int x = 20; // Hides Parent.x
    }

    public class Main {
    public static void main(String[] args) {
    Parent obj = new Child();

            System.out.println(obj.x);      // 10
            System.out.println(Child.x);    // 20
            System.out.println(Parent.x);   // 10
        }

    }

---

## Important Rules

- Static variables are resolved at **compile time**

- Access depends on **reference type**

- No runtime polymorphism

- Should be accessed using class name (best practice)

✔ Correct way:

    System.out.println(Parent.x);
    System.out.println(Child.x);
