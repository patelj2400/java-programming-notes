# Variable Shadowing

---

## 1. What is Variable Shadowing?

**Variable Shadowing** happens when a **local variable** or **method parameter** has the same name as an **instance (class) variable**.

In that case, the inner variable **"shadows"** (hides) the outer variable.

#### Example : Instance Variable Shadowed by Local Variable

    class Student {
    int age = 20; // Instance variable

        void display() {
            int age = 25;   // Local variable (shadows instance variable)
            System.out.println(age);
        }
    }

#### What happens?

- `int age = 25;` shadows the instance variable.

- `System.out.println(age);` prints **25**, not 20.

---

## 2. How to Access Shadowed Instance Variable?

### Example :

Use `this` keyword.

    class Student {
    int age = 20;

        void display() {
            int age = 25;
            System.out.println(age);        // 25 (local)
            System.out.println(this.age);   // 20 (instance)
        }

    }

#### Why?

- `this.age` → refers to the current object's instance variable.

---

### Example : Constructor Parameter Shadowing

This is the **most common real-world case**.

    class Student {
    int age;

        Student(int age) {
            this.age = age;
        }

    }

#### Explanation

- `int age` (parameter) shadows `int age` (instance variable).

- `this.age` → instance variable

- `age` → parameter (alone refers to method parameter.)

If you write:

    age = age;

- Nothing changes!
- Both refer to the parameter.

---

## Why Shadowing Matters in DSA

When solving problems:

- You often pass variables into constructors.

- You frequently use class fields for state.

- Confusion between local and instance variables can cause bugs.

---

## Visual Understanding

Imagine two boxes with the same name:

    Instance variable: age = 20
    Local variable: age = 25

Java always prefers:

1.  Local variable
2.  Method parameter
3.  Instance variable (using `this`)

---

## Shadowing vs Hiding vs Overriding

| Concept    | Happens In       | What Happens                           |
| ---------- | ---------------- | -------------------------------------- |
| Shadowing  | Variables        | Inner variable hides outer variable    |
| Hiding     | Static methods   | Child class hides parent static method |
| Overriding | Instance methods | Child class changes parent behavior    |

---

## Key Rules

✅ Shadowing happens in nested scopes.
✅ Local variable has higher priority than instance variable
✅ Use `this` to access instance variable
✅ Common in constructors
✅ Shadowing improves readability in setters but should be used carefully.
❌ Java does NOT allow two local variables with same name in same scope

---

## Interview Definition (Short)

👉 Variable shadowing is when a local variable or parameter has the same name as a class-level variable, hiding the outer variable within its scope.
