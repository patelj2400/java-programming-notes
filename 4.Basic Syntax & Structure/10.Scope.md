# Scope in Java

In Java, **scope** defines the **region of a program where a variable is accessible**.

In simple words:

> 👉 Scope tells us **where we can use a variable** in our program.

---

## 1.What is Scope?

Scope means the **visibility or lifetime area** of a variable.

If a variable is declared inside a block `{ }`, it can only be used inside that block.

---

## 2. Types of Scope in Java

In Java, scope mainly depends on **where the variable is declared**.

##### 1. Local Scope (Method Scope)

##### 2. Block Scope

##### 3. Class Scope (Instance Variables)

##### 4. Static Scope (Class-Level Static Variables)

---

### 1. Local Scope (Method Scope)

A variable declared **inside a method** is called a **local variable**.

- Declared inside a method/block.
- Accessible **only inside that block**.

### Example:

    class Test {
        void display() {
            int x = 10; // local variable
            System.out.println(x);
        }
    }

✔ `x` is accessible only inside `display()`\
❌ You cannot use `x` outside this method.

---

### 2. Block Scope

A variable declared inside a **block `{}`** (like inside `if`, `for`, `while`) is accessible only inside that block.

- Declared inside a class but **outside methods**.

- Belongs to an object.

### Example:

    class Test {
        public static void main(String[] args)
        {
            if (true) {
                int y = 20; // block scope
                System.out.println(y);
            }

                // System.out.println(y);  ❌ Error\
        }

    }

✔ `y` works inside `if`\
❌ Outside → compile-time error

---

### 3.Class Scope (Instance Variable)

A variable declared **inside a class but outside methods** is called an **instance variable**.

👉 It is accessible to all methods of that class.

### Example:

    class Student {
    int age = 18; // instance variable

        void showAge() {
            System.out.println(age);
        }

    }

✔ `age` can be used in any method of the class\
✔ Each object gets its own copy

---

### 4. Static Scope (Class-Level Static Variable)

A variable declared with `static` keyword belongs to the class itself.

- Declared with `static`.

- Shared among all objects.

#### Example:

    class Student {
    static String school = "ABC School";

        void showSchool() {
            System.out.println(school);
        }

    }

✔ One common copy for all objects\
✔ Accessed using: `Student.school`

---

## 3. Visual Understanding of Scope

Think of scope like rooms in a house:

- 🏠 Class → Whole house

- 🚪 Method → One room

- 📦 Block → Small box inside room

A variable inside a box cannot go outside the box.

---

## 4. Important Scope Rules

#### Rule 1: Inner block can access outer variable

    int a = 10;

    if (true) {
        System.out.println(a); // ✔ allowed
    }

#### Rule 2: Outer block cannot access inner variable

    if (true) {
        int b = 20;
    }

    // System.out.println(b); ❌ not allowed

---

## 5. Scope vs Lifetime

Many students confuse these two.

| Scope                          | Lifetime                           |
| ------------------------------ | ---------------------------------- |
| Where variable can be accessed | How long variable exists in memory |

Example:

- Local variable → Exists only during method execution.

- Instance variable → Exists as long as object exists.

---

## 6. Why Scope is Important in DSA?

When solving Data Structures problems:

- Loop variables (`i`, `j`) have block scope

- Recursive calls depend on local scope

- Global/static variables affect entire program behavior

If scope is misunderstood:

- You may get compilation errors

- Logic errors

- Memory issues

---

## 7. Common Mistake (Very Important)

### Variable Shadowing

When local variable has same name as instance variable.

    class Test {
    int x = 10;

        void show() {
            int x = 20;   // shadows instance variable
            System.out.println(x);
        }

    }

Output → `20`

To access instance variable:

    System.out.println(this.x);
