# Variables

A **variable** is a named memory location used to store data that can change during program execution.

👉 Think of it as a **labeled box in memory** where you store values.

> It acts like a container that holds a value.

---

## 1.Real-Life Analogy

- `age = 25` → A box labeled **age** storing value **25**

- `name = "Jay"` → A box labeled **name** storing **Jay**

---

## 2.Example in Java

    int age = 25;
    String name = "Jay";
    double salary = 50000.50;

Here:

- `int`, `String`, `double` → **Data types**

- `age`, `name`, `salary` → **Variable names**

- `25`, `"Jay"`, `50000.50` → **Values**

---

## 3.Why Variables Exist?

Computers operate on **memory**.

When you write:

    int x = 10;

👉 Java:

1.  Reserves memory space

2.  Stores value `10`

3.  Associates that memory with name `x`

Without variables, programs can't store or manipulate data.

#### Why Do We Need Variables?

1.  To store user input

2.  To store intermediate results

3.  To reuse values

4.  To make code readable and maintainable

---

## 4.Variable Structure

    dataType variableName = value;

Example:

    int marks = 90;

---

## 5.Types of Variables (Java)

### 1.Local Variables

    void show() {
        int x = 10; // Local variable
    }

- Declared inside a method
- Scope limited to that method

### 2.Instance Variables

    class Student {
    int age; // Instance variable
    }

- Declared inside a class but outside methods
- Belong to an object

### 3.Static Variables

    class Student {
        static String school = "ABC School";
    }

- Declared using static
- Shared among all objects

---

## 6.Primitive vs Non-Primitive Variables

### ✅ Primitive (Store actual value)

- `int`

- `double`

- `char`

- `boolean`

int a = 5;

Stored directly in memory.

---

### ✅ Non-Primitive (Reference Variables)

- `String`

- Arrays

- Objects

String name = "Jay";

Here:

- Variable stores **reference (address)**

- Actual object stored in heap

---

## 7.Memory Perspective (Very Important for DSA 🔥)

- Primitive variables → Stored in **stack memory**

- Object variables → Reference stored in stack, object stored in heap

- Garbage Collector removes unused objects

### Stack vs Heap

| Memory | Stores          |
| ------ | --------------- |
| Stack  | Local variables |
| Heap   | Objects         |

Example:

    int a = 10;
    String s = "Hello";

- `a` → Stack

- `s` → Reference in Stack

- `"Hello"` → Heap

---

## 8.Variable Rules in Java

✔ Must start with letter, `_`, or `$`\
✔ Cannot start with number\
✔ Case-sensitive (`age` ≠ `Age`)\
✔ Cannot use keywords (`int`, `class`, etc.)

---

## 9.Variables in DSA

In Data Structures & Algorithms:

- Variables hold counters

- Store indexes

- Temporary swap values

- Track minimum/maximum

- Store recursion states

Example (Swap Logic):

    int temp = a;
    a = b;
    b = temp;
