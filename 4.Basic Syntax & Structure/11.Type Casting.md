# Type Casting in Java

---

## 1.What is Type Casting?

**Type Casting** means converting one data type into another data type.

In Java, this usually happens between:

- Primitive data types (int, double, float, etc.)

- Parent and child classes (OOP casting)

---

## 2.Type Casting in Primitive Data Types

There are **two types**:

1.  Widening (Implicit Casting)

2.  Narrowing (Explicit Casting)

---

### A) Widening Casting (Implicit / Automatic)

- Small data type → Bigger data type
- Done automatically by Java
- No data loss
- No explicit casting required

#### Memory Size Order in Java

    byte → short → int → long → float → double

#### Example:

    int a = 10;
    double b = a; // Automatic casting

    System.out.println(b); // 10.0

✔ int → double
✔ No data loss
✔ Done automatically
✔ No cast required

---

#### B) Narrowing Casting (Explicit / Manual)

- Bigger data type → Smaller data type

- Must be done manually

- May cause data loss

#### Example:

    double a = 10.75;
    int b = (int) a; // Manual casting

    System.out.println(b); // 10

✔ double → int
❌ Decimal part lost
✔ Must write `(int)`

---

### Visual Representation

#### Widening Conversion (Safe)

byte (1 byte)
↓
short (2 bytes)
↓
int (4 bytes)
↓
long (8 bytes)
↓
float (4 bytes)
↓
double (8 bytes)

#### Narrowing Conversion (Risky)

Reverse of above ⬆

---

## 3. Why Type Casting is Needed?

#### 1. During Calculations

    int a = 5;
    int b = 2;

    double result = (double)a / b;
    System.out.println(result); // 2.5

Without casting:

    System.out.println(a / b); // 2 (integer division)

---

#### 2. While Taking Input

    import java.util.Scanner;

    Scanner sc = new Scanner(System.in);
    double price = sc.nextDouble();

    int roundedPrice = (int) price;

---

## 4. Type Promotion in Expressions

Java automatically promotes smaller types to int during arithmetic.

    byte a = 10;
    byte b = 20;

    int result = a + b; // NOT byte

Even though both are byte → result becomes int.

---

## 5.Casting in Non-Primitive Types (OOP)

In OOP, casting happens between **parent and child classes**.

There are two types:

#### Upcasting (Implicit)

Child → Parent

    Animal a = new Dog();

✔ Automatic
✔ Safe

---

#### Downcasting (Explicit)

Parent → Child

    Animal a = new Dog();
    Dog d = (Dog) a;

✔ Manual
⚠ Can cause ClassCastException

---

## Important Rules

#### ✔ You cannot cast boolean to any other type.

    boolean b = true;

    // int x = (int) b; ❌ Not allowed

---

#### ✔ You cannot cast unrelated objects.

    String s = "Hello";
    // Integer i = (Integer) s; ❌ Error

---

## Quick Comparison Table

| Type        | Automatic? | Data Loss?     | Example      |
| ----------- | ---------- | -------------- | ------------ |
| Widening    | Yes        | No             | int → double |
| Narrowing   | No         | Yes (possible) | double → int |
| Upcasting   | Yes        | No             | Dog → Animal |
| Downcasting | No         | Possible error | Animal → Dog |

---

## Special Case: char

- `char` can be cast to `int` (ASCII value)

- Integer division always returns int

- Type promotion happens automatically in expressions

- Casting does not change original variable value

Example:

    char ch = 'A';
    int x = ch;
    System.out.println(x); // 65

✔ char is promoted to int

    int x = 65;
    char c = (char) x;

Requires explicit cast.

---

## Final Definition (Exam Ready)

> Type casting is the process of converting one data type into another data type in Java, either automatically (widening) or manually (narrowing).
