# Java Recursion

Recursion is a **technique where a method calls itself** to solve a smaller version of the same problem.

In DSA, recursion is extremely important because many problems (trees, graphs, backtracking, divide & conquer) are naturally recursive.

---

## 1. What is Recursion?

A recursive method:

1.  Calls itself

2.  Has a **base case** (stopping condition)

3.  Works on a **smaller subproblem**

### Basic Structure

    returnType methodName(parameters) {
        if (baseCondition) {
            return value; // stop recursion
        }
        return methodName(smallerInput); // recursive call
    }

---

## 2. Example -- Print Numbers 1 to N

    static void print(int n) {
        if (n == 0) return; // base case
        print(n - 1); // recursive call
        System.out.println(n);
    }

### Flow for n = 3

Call stack:

print(3)
&nbsp;&nbsp;print(2)
&nbsp;&nbsp;&nbsp;&nbsp;print(1)
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;print(0) → stops

Then printing happens while returning:

1
2
3

👉 This is called **Backtracking Phase** (work after recursive call).

---

## 3. How Recursion Works Internally

Recursion uses **Stack Memory**.

Each method call:

- Gets its own copy of variables
- Is pushed into the call stack
- Removed when finished
- When base case is reached → calls start returning

If too many calls → **StackOverflowError**

---

## 4. Recursion Tree (Important for DSA)

Example: Fibonacci

    static int fib(int n) {
        if (n <= 1) return n;
        return fib(n - 1) + fib(n - 2);
    }

For `fib(4)`:

              4
            /   \
          3       2
         /  \    /  \
        2     1 1    0
      /   \
     1     0

Time Complexity: **O(2^n)**\
Space Complexity: **O(n)** (stack depth)

---

## 5. Types of Recursion (Interview Important)

#### 1. Linear Recursion

One recursive call.

Example:

factorial(n) = n \* factorial(n-1)

---

#### 2. Tree / Multiple Recursion

More than one recursive call.

Example:

fib(n-1) + fib(n-2)

---

#### 3. Tail Recursion

Recursive call is the **last statement**.

    static void print(int n) {
        if (n == 0) return;
        System.out.println(n);
        print(n - 1); // last operation
    }

⚠ Java does **NOT** optimize tail recursion automatically.

---

#### 4. Indirect Recursion

    Method A calls B, and B calls A.

---

## 6. Base Case vs Recursive Case

| Part           | Purpose                           |
| -------------- | --------------------------------- |
| Base Case      | Stops infinite calls              |
| Recursive Case | Breaks problem into smaller piece |

    Without base case → Infinite recursion → StackOverflowError.

    Wrong Base Condition  → Can cause infinite recursion.

## 8. Recursion vs Iteration

| Recursion                     | Loop                                                 |
| ----------------------------- | ---------------------------------------------------- |
| Uses method calls             | Uses iteration                                       |
| Uses stack memory             | Uses variables (less memory)                         |
| Clean for tree/graph problems | Better for simple loops (repetition), Usually faster |
| Risk of stack overflow        | Memory efficient                                     |

## 9. Important Interview Concepts

#### Recurrence Relation

Example:

    T(n) = T(n-1) + O(1)

#### Stack Space = Height of recursion

#### Dry Run Method

Always:

1.  Identify base case

2.  Write recursive step

3.  Dry run for small input

4.  Draw recursion tree

---

## Key Points to Remember

✔ Always define a base case
✔ Move towards base case
✔ Calls itself
✔ Each call uses stack memory
✔ Risk of StackOverflowError if too deep
