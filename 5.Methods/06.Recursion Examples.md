## Example 1: Factorial

**Factorial formula:**

    n! = n×(n-1)!

**Code:**

    public class RecursionExample {

        static int factorial(int n) {
            if (n == 0) {   // Base case
                return 1;
            }
            return n * factorial(n - 1);  // Recursive case
        }

        public static void main(String[] args) {
            System.out.println(factorial(5));
        }
    }

### How it Works (factorial(5))

5 × factorial(4)
5 × 4 × factorial(3)
5 × 4 × 3 × factorial(2)
5 × 4 × 3 × 2 × factorial(1)
5 × 4 × 3 × 2 × 1
= 120

    Result = 120

## Example 2: Print Numbers 1 to N

    static void printNumbers(int n) {
        if (n == 0)
            return;
        printNumbers(n - 1);
        System.out.print(n + " ");
    }

Output for `printNumbers(5)`:

    1 2 3 4 5

## Example 3 : Fibonacci

Fibonacci formula:

    F(n) = F(n-1) + F(n-2)

Code:

    static int fibonacci(int n) {
        if (n <= 1) {
            return n;  // Base case
        }
        return fibonacci(n - 1) + fibonacci(n - 2);
    }

> Note: This version is slow for large numbers because it repeats calculations.

## How Recursion Works Internally

- Each recursive call is stored in **Stack Memory**

- Java uses the **call stack**

- When base case is reached → calls start returning

If no base case → ❌ **StackOverflowError**
