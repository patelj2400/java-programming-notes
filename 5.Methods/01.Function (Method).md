## What is a Function (Method) in Java?

In Java, a **function is called a method**.

A **method** is a block of code that performs a specific task and runs only when it is called.

It helps you:

- Reuse code

- Organize logic

- Reduce duplication

- Improve readability
- Break big problems into smaller parts

---

## 1. Basic Syntax of a Method

    accessModifier returnType methodName(parameters) {
    // body of method
    }

Creating a method is not enough — we must call it.

#### Example:

    public class Main {

        static void greet() {
            System.out.println("Hello Jay!");
        }

        public static void main(String[] args) {
            greet();  // method call
        }

    }

---

### Parts of a Method Explained

| Part     | Meaning                       |
| -------- | ----------------------------- |
| `public` | Access modifier               |
| `static` | Belongs to class (not object) |
| `void`   | No return value               |
| `greet`  | Method name                   |
| `()`     | Parameters                    |
| `{}`     | Method body                   |

---

## 2. Types of Methods in Java

### 1. Built-in Methods

Already defined inside Java libraries.

Example:

- `System.out.println()`

- `Math.max()`

Example using Math:

    int max = Math.max(10, 20);

---

### 2. User-Defined Methods

Methods created by the programmer.

    static int add(int a, int b) {
        return a + b;
    }

---

## 3. Method With Parameters and Return Value

#### 🔹 `void` Return Type

Means the method returns nothing.

    public static void printMessage() {
        System.out.println("Welcome!");
    }

#### 🔹 Method With Return an Integer

    public static int add(int a, int b) {
        return a + b;
    }

Calling it:

    int result = add(10, 20);
    System.out.println(result);

Output:

    30

👉 Important:

- `return` ends the function.

- After `return`, no code executes.

#### 🔹 Methods With Integer Parameters (Arguments)

    public class Main {

      static int square(int number) {
          return number * number;
      }

      public static void main(String[] args) {
          int result = square(5);
          System.out.println(result);
      }
    }

Here:

- `number` → parameter

- `5` → argument

- `int` → return type

#### 🔹 Method With String Return Type

    public static String greet() {
        return "How are you?";
    }

Calling:

    String message = greet();
    System.out.println(message);

Output:

    How are you?

#### 🔹 Method With String Parameter (Arguments)

    public static String greetUser(String name) {
        return "Hello " + name;
    }

Calling:

    String msg = greetUser("Kunal");
    System.out.println(msg);

Output:

    Hello Kunal

#### 🔹 Methods With Multiple Parameters (Arguments)

Parameters allow passing values to methods.

    public static int sum(int a, int b) {
        return a + b;
    }

Calling it

    public static void main(String[] args) {
        int answer = sum(5, 6);
        System.out.println(answer);
    }

Output:

    11

## 3. Why Methods Are Important in DSA

methods are critical because:

- Every algorithm is written inside methods.

- Recursion is based on methods calling themselves.

- Clean modular code is expected in interviews.

Example (DSA style):

    static int factorial(int n) {
    if (n <= 1) return 1;
    return n \* factorial(n - 1);
    }

## 4. Method Categories (Very Important)

### ✔ Based on Return Type

1.  `void` methods (no return)

2.  Non-void methods (return something)

### ✔ Based on Parameters

1.  No parameters

2.  With parameters

## 5. Method vs Function

In Java:

- Everything must be inside a class.

- So technically Java has **methods**, not standalone functions.

But casually people say "function".

---

# Simple Definition (Interview Ready)

> A method in Java is a reusable block of code defined inside a class that performs a specific task and can optionally take parameters and return a value.
