# Scope in Java

**Scope** means the area in a program where a variable is accessible.

In Java, scope is mainly of three types:

1.  **Method Scope**

2.  **Block Scope**

3.  **Loop Scope**

---

## 1.Method Scope

===================

A variable declared **inside a method** is accessible **only within that method**.

    public class Demo {
        public static void main(String[] args) {
            int x = 10;   // Method scope
            System.out.println(x);
        }
    }

✔ `x` can be used anywhere inside `main()`
❌ `x` cannot be used outside `main()`

If you try:

    System.out.println(x); // ❌ Error

You'll get:

    cannot find symbol

---

## 2. Block Scope

A **block** is any code inside `{ }`.

Examples:

- if block

- else block

- switch block

- standalone `{ }`

### Example:

    public class Demo {
        public static void main(String[] args)
        {
            int a = 5;

            if (a > 0) {
                int b = 10;  // Block scope
                System.out.println(b);
            }
            // System.out.println(b); ❌ Error
        }
    }

✔ `b` is accessible only inside the `if` block
❌ Outside the block → compile-time error

---

## 3. Loop Scope

Loop variables are also **block scoped**.

#### Example 1: Variable declared inside loop

    for (int i = 0; i < 5; i++) {
        System.out.println(i);
    }

    // System.out.println(i); ❌ Error

✔ `i` exists only inside the `for` loop
❌ Not accessible outside

---

#### Example 2: Variable declared outside loop

    int i;

    for (i = 0; i < 5; i++) {
        System.out.println(i);
    }

    System.out.println(i); // ✔ Works

Now `i` has **method scope**, not loop scope.

---

## Visual Understanding

=======================

Think of scope like **visibility area**:

Method\
 ├── Block (if)
│ └── Variable visible only here
├── Loop
│ └── Variable visible only here

Inner block variables:

- Can access outer variables

- Outer block cannot access inner variables

---

## Important DSA Rule

In coding interviews:

✔ Declare variables **as locally as possible**
✔ Avoid unnecessary global variables
✔ Helps prevent logical bugs in loops & recursion

Example bug:

    for (int i = 0; i < n; i++) {
        int sum = 0; // ❌ resets every iteration
    }

Correct:

    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += i;
    }

---

## Scope Hierarchy

Class Scope
↓
Method Scope
↓
Block Scope
↓
Loop Scope

✔ Scope is decided by { } braces.
✔ Inner scope can access outer variables.
✔ Outer scope cannot access inner variables.
✔ Java does not allow variable redeclaration in the same scope.

---

## Quick Comparison Table

| Scope Type   | Where Declared | Accessible Where       |
| ------------ | -------------- | ---------------------- |
| Method Scope | Inside method  | Entire method          |
| Block Scope  | Inside `{}`    | Only inside that block |
| Loop Scope   | Inside loop    | Only inside loop       |
