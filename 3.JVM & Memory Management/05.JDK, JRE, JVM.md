# Java Architecture Overview

## 1.JVM (Java Virtual Machine)

![https://upload.wikimedia.org/wikipedia/commons/d/dd/JvmSpec7.png](https://upload.wikimedia.org/wikipedia/commons/d/dd/JvmSpec7.png)

### 🔹 What is JVM?

**JVM is a virtual machine that runs Java bytecode.**

It is responsible for:

- Loading class files
- Verifying bytecode
- Executing code
- Memory management
- Garbage collection
- Bytecode execution

👉 JVM converts **Bytecode (.class)** → **Machine Code**

👉 JVM is the engine that runs Java programs.

- It executes bytecode (.class files).
- It converts bytecode → machine code.
- It makes Java platform-independent.

> JVM is platform-dependent (different JVM for Windows, Mac, Linux), but Java code is platform-independent.

---

### 🔹 Why JVM is Powerful?

Because of JVM, Java follows:

> **WORA -- Write Once, Run Anywhere**

A Java program compiled on Windows can run on Linux or Mac --- if JVM is installed.

---

### 🔹 JVM Main Components

1.  Class Loader

2.  Method Area

3.  Heap

4.  Stack

5.  Program Counter Register

6.  Garbage Collector

---

### 🔹 Example Flow

    class Test {
        public static void main(String[] args)
        {
            System.out.println("Hello");
        }
    }

Step 1 → `javac Test.java` → Generates `Test.class` (Bytecode)\
Step 2 → `java Test` → JVM executes it

## 2.JRE (Java Runtime Environment)

![https://miro.medium.com/1%2AMHpdx5oni3ymFQDKDFbWLQ.png](https://miro.medium.com/1%2AMHpdx5oni3ymFQDKDFbWLQ.png)

### 🔹 What is JRE?

**JRE = JVM + Libraries + Supporting Files**

It is used to **run Java applications**, not to develop them.

If you only want to:

- Run a Java application

- Not write code

Then JRE is enough.

---

### 🔹 What JRE Contains?

- JVM

- Core libraries (java.lang, java.util, etc.)

- Supporting files

❌ It does NOT contain compiler (javac)

---

## 3.JDK (Java Development Kit)

### 🔹 What is JDK?

**JDK = JRE + Development Tools**

It is used to:

- Write Java code

- Compile code

- Debug
- Run

- Package applications

---

### 🔹 What JDK Contains?

- JRE

- JVM

- Compiler (javac)

- Debugger

- javadoc

- jar tool

- jshell
- Documentation tools
- Other development utilities

---

## Relationship Diagram (Most Important for Interviews)

JDK
├── JRE
│ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;├── JVM
│ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;├── Libraries
│
├── Compiler (javac)
├── Debugger
├── Tools

- JVM executes Java bytecode.
- JRE provides runtime environment (JVM + libraries).
- JDK provides development tools (JRE + compiler + tools).

## Real-Life Analogy

Think of Java like cooking 🍳

- 👨‍🍳 JDK → Full kitchen (you can cook + eat)

- 🍽 JRE → Only dining area (you can eat but not cook)

- 🔥 JVM → Gas stove (actually cooks food)

## Important Extra (Advanced)

- Bytecode runs on JVM, not directly on OS.

- JVM is part of the **Java platform developed by Oracle Corporation**.
