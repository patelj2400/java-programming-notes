## 1.What is a Programming Language?

A **programming language** is a way to give instructions to a computer so it can perform tasks.

Computers understand only **machine code (0s and 1s)**.\
Programming languages act as a **bridge between humans and machines**.

👉 Example:

    System.out.println("Hello World");

This gets converted into machine code before execution.

---

## 2.Why Programming Languages Exist?

Without programming languages, we would have to write:

    010101010101010101010101010101

Instead, we write human-readable instructions like:

    int a = 10;
    int b = 20;

    System.out.println(a + b);

Much easier, right? 😊

### 1.Compiled Language

Example:

- C

- C++

✅ Faster execution
❌ Platform dependent

---

### 2.Interpreted Language

Code → Line-by-line execution

Example:

- Python

✅ Easy debugging
❌ Slightly slower

---

### 3.Hybrid (Java Model)

✔ Secure
✔ Widely used in DSA & interviews

## Interview Quick Questions

##### 1. Difference between compiler & interpreter?

    👉 Compiler translates the whole program at once before execution.
    👉 Interpreter translates and executes line by line.

##### 2. Why is Java platform independent?

    👉 Because Java compiles code into bytecode, which runs on the JVM (Java Virtual Machine).
    👉 JVM makes Java “Write Once, Run Anywhere (WORA)”.

##### 3. What is bytecode?

    👉 Intermediate code generated by Java compiler (.class file).
    👉 It is executed by the JVM, not directly by the operating system.

##### 4. What is static typing?

    👉 Type of variable is checked at compile time.
    👉 Example: In Java, int a = 10; (type cannot change later).

##### 5. High-level vs low-level language?

    👉 High-level: Human-readable, easier (Java, Python).
    👉 Low-level: Close to machine language (Assembly, Machine code).

##### 6. Procedural vs OOP?

    👉 Procedural: Focus on functions/procedures (C).
    👉 OOP: Focus on objects & classes (Java).

##### 7. What is the difference between coding and programming?

    👉 Coding: Writing code.
    👉 Programming: Complete process (design, coding, testing, debugging).

##### 8. What is a compiler?

    👉 A software that converts high-level language code into machine code or bytecode before execution.

##### 9. Why is Java platform independent?

    👉 Because it runs on JVM (Write Once, Run Anywhere).
