## Object Creation in Java (Ways)

In Java, objects are created in multiple ways. Let's understand all important ways clearly 👇

---

## 1. Using the `new` Keyword (Most Common)

This is the **standard and most used method**.

#### Syntax

    ClassName obj = new ClassName();

#### Example

    class Student {
        String name = "Jay";
    }

    public class Main {
        public static void main(String[] args) {
            Student s1 = new Student();  // object creation
            System.out.println(s1.name);
        }
    }

#### Steps happening internally

1.  JVM allocates **memory in heap**

2.  **Constructor is called**

3.  Object reference is returned

---

## 2. Using `Class.forName().newInstance()`

Object can be created using Reflection API.

Syntax:

    ClassName obj = (ClassName) Class.forName("ClassName").newInstance();

Example:

    Student s1 = (Student) Class.forName("Student").newInstance();

This method uses **reflection**.

### Example

    class Student {
        Student() {
            System.out.println("Object Created");
        }
    }

    public class Main {
        public static void main(String[] args) throws Exception {
            Class cls = Class.forName("Student");
            Student s = (Student) cls.newInstance();
        }
    }

### Note

`newInstance()` is **deprecated after Java 9**. Instead use:

    Student s = Student.class.getDeclaredConstructor().newInstance();

✔ Constructor must be public
✔ Throws checked exceptions
✔ Mostly used in frameworks

⚠ newInstance() is deprecated (use getDeclaredConstructor().newInstance() instead)

---

## 3. Using `clone()`

Creates a **copy of an existing object**.

### Example

    class Student implements Cloneable {
        int id = 10;

        public Object clone() throws CloneNotSupportedException {
            return super.clone();
        }

    }

    public class Main {
        public static void main(String[] args) throws Exception
        {
            Student s1 = new Student();
            Student s2 = (Student) s1.clone();
            System.out.println(s2.id);
        }
    }

#### Important

Class must implement **Cloneable interface**.

✔ Class must implement Cloneable
✔ Creates shallow copy (by default)

---

## 4. Using **Deserialization**

An object can be recreated from a **saved file/stream**.

#### Example

    ObjectInputStream in = new ObjectInputStream(new FileInputStream("obj.txt"));

    Student s = (Student) in.readObject();

Used in:

- File storage
- Network communication
- Distributed systems

✔ Class must implement Serializable
✔ Constructor is NOT called

---

## 5. Using **Factory Methods**

Objects can be created using **static factory methods**.

    Student s1 = Student.getInstance();

#### Example

    class Student {

        private Student() {}

        static Student createObject() {
            return new Student();
        }

    }

    public class Main {
        public static void main(String[] args) {
            Student s = Student.createObject();
        }
    }

Used in many Java classes like:

- `Integer.valueOf()`

- `Runtime.getRuntime()`

#### Example:

    Integer.valueOf(10);

✔ Used in Singleton pattern
✔ Controlled object creation

---

## 6. Using Anonymous Object

Object created without reference variable.

    new Student().show();

✔ Used for one-time use
✔ No reference stored

---

## Quick Summary

| Method          | Constructor Called? | Special Requirement    | Usage                      |
| --------------- | ------------------- | ---------------------- | -------------------------- |
| new             | ✅ Yes              | Normal way             | Most common                |
| Reflection      | ✅ Yes              | Exception handling     | Dynamic class loading      |
| clone()         | ❌ No               | Cloneable interface    | Copy object                |
| Deserialization | ❌ No               | Serializable interface | Recreate from file         |
| Factory Method  | Depends             | Custom logic           | Controlled object creation |
| Anonymous       | ✅ Yes              | No reference           | used only once             |

---

✅ **Most used in real programs:**

- `new`

- Factory methods
