# Introduction to **Object-Oriented Programming (OOP)**

---

## 1. What is OOP?

**Object-Oriented Programming (OOP)** is a programming paradigm based on the concept of **objects**.\
Objects represent **real-world entities** and contain:

- **State (Data /Variables / Attributes)**

- **Behavior (Methods / Functions)**

Instead of writing programs as a sequence of instructions, OOP organizes code into **objects that interact with each other**.

Example real-world objects:

- Car

- Student

- Bank Account

- Mobile Phone

Each object has **properties** and **actions**.

Example:

    Car
    Properties: color, speed, brand
    Actions: start(), stop(), accelerate()

In Java, OOP is the core concept used to build applications.

---

## 2. Why OOP is Used

OOP helps in building **large, complex, and maintainable software**.

#### Advantages

1.  **Code Reusability**
    - Using inheritance we can reuse existing code.

2.  **Modularity**
    - Program divided into independent objects.

3.  **Easy Maintenance and extend**
    - Changes in one class do not affect others.

4.  **Security**
    - Data hiding using encapsulation.

5.  **Real-world modeling**
    - Programs become easier to understand.

## Basic Terminology in OOP

### 1. Class

A **class** is a blueprint or template used to create objects.

Example:

    class Car {
        String color;
        int speed;
    }

Here **Car** is a class.

---

### 2. Object

An **object** is an instance of a class.

Example:

    Car c1 = new Car();

Here **c1** is an object.

---

### 3. Attributes (Fields / Variables)

Attributes store **data of an object**.

Example:

    class Student {
        String name;
        int age;
    }

---

### 4. Methods (Functions)

Methods define **behavior of objects**.

Example:

    class Car {
        void start() {
            System.out.println("Car started");
        }
    }

---

## The Four Pillars of OOP

## 1. Encapsulation

Bundling **data and methods together inside a class** and restricting access using access modifiers.

Example:

    class BankAccount {
    private double balance;

        public void deposit(double amount) {
            balance += amount;
        }

    }

---

## 2. Inheritance

Allows one class to **inherit properties from another class**.

    class Animal {
        void eat() {}
    }

    class Dog extends Animal {
        void bark() {}
    }

Dog gets **eat() method** from Animal.

---

## 3. Polymorphism

Polymorphism means **many forms**.

Example:

    void add(int a, int b)
    void add(double a, double b)

Same method name → different behavior.

Types:

- Compile-time polymorphism (Method Overloading)

- Runtime polymorphism (Method Overriding)

---

## 4. Abstraction

Hiding implementation details and showing only essential features.

Example:

    abstract class Vehicle {
        abstract void start();
    }

---

# Simple OOP Example in Java

    class Student {

        String name;
        int age;

        void display() {
            System.out.println(name + " " + age);
        }

        public static void main(String[] args) {

            Student s1 = new Student();
            s1.name = "Jay";
            s1.age = 20;

            s1.display();
        }

    }

Output

    Jay 20

## Procedural Programming vs OOP

| Procedural Programming         | OOP                            |
| ------------------------------ | ------------------------------ |
| Focus on functions             | Focus on objects               |
| Data and functions separate    | Data and methods together      |
| Hard to maintain large systems | Easier to manage large systems |
| Example: C                     | Example: Java, C++, Python     |

## Very Short Definition (Interview)

**Object-Oriented Programming (OOP)** is a programming paradigm that organizes software design around **objects containing data and methods**, using concepts like **encapsulation, inheritance, polymorphism, and abstraction**.
