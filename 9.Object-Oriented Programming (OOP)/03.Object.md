## What is an Object?

In **Object-Oriented Programming (OOP)**, an **Object** is an **instance of a class**.

- A **class** is a **blueprint or template**.

- An **object** is the **real-world implementation of that blueprint**.

📌 **Definition:**
An **object** is a **real-world entity that contains data (variables) and behavior (methods)** defined by a class.

---

## Real Life Example

Think about a **Car**.

- **Class:** Car

- **Objects:** BMW, Audi, Tesla

Each car object has:

**Properties (Data / Variables):**

- color

- speed

- model

**Behaviors (Methods / Functions):**

- start()

- accelerate()

- brake()

So:

Class → Car
Objects → BMW, Audi, Tesla

---

## Object in Java

In Java, an object is created using the **`new` keyword**.

#### Syntax

    ClassName objectName = new ClassName();

---

#### Example

    class Car {
    String color;

        void drive() {
            System.out.println("Car is driving");
        }

    }

    public class Main {
    public static void main(String[] args) {

            Car c1 = new Car();   // Object created

            c1.color = "Red";
            c1.drive();
        }

    }

#### Output

    Car is driving

---

## Memory Concept

When an object is created:

    Car c1 = new Car();

Memory allocation happens in **Heap Memory**.

    Stack Memory    Heap Memory
    -------------   ----------------
    c1 -----------► Car Object
                    color
                    drive()

- `c1` → reference variable (stored in stack)

- Actual **object** → stored in heap memory

---

## Key Characteristics of an Object

An object has **three main features**:

1. **State**

- Data stored in variables

- Example: color = red

2. **Behavior**

- Actions performed by methods

- Example: drive(), brake()

3. **Identity**

- Unique reference in memory
