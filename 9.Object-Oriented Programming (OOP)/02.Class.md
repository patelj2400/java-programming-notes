# Class in OOP (Java)

---

A **Class** is a **blueprint or template used to create objects**.
It defines **properties (variables)** and **behaviors (methods)** that the objects created from it will have.

In simple words:

> **Class = Blueprint**
> **Object = Real-world instance created from the blueprint**

#### Real-Life Example

Think of a **Car blueprint**.

The blueprint defines:

- Color

- Speed

- Brand

And actions:

- Start engine behavior
- Stop
- Accelerate

But the blueprint itself is **not a real car**.
When we manufacture cars using that blueprint, those cars are **objects**.

Class → Car
Objects → BMW, Audi, Tesla

---

## Definition in Programming

> A **class is a user-defined data type that groups variables and methods into a single unit.**

It is the **foundation of Object Oriented Programming (OOP)**.

---

## Basic Structure of a Class in Java

    class Car {

        String color;   // variable (property)
        int speed;      // variable

        void drive() {  // method (behavior)
            System.out.println("Car is driving");
        }

    }

#### Explanation

| Part           | Meaning                    |
| -------------- | -------------------------- |
| `class Car`    | Declares a class named Car |
| `String color` | Instance variable          |
| `int speed`    | Instance variable          |
| `drive()`      | Method defining behavior   |

---

## Creating an Object from a Class

    public class Main {
        public static void main(String[] args) {

            Car c1 = new Car();   // object creation

            c1.color = "Red";
            c1.speed = 120;

            c1.drive();
        }

    }

### What Happens Here

1.  `Car` → Class definition

2.  `new Car()` → Creates an object in memory

3.  `c1` → Reference variable pointing to that object

---

## Memory Concept (Important for DSA)

    Stack Memory    Heap Memory
    -------------   ----------------
    c1 -----------→ Car Object
                    color = "Red"
                    speed = 120

- **Reference variable (`c1`) → stored in Stack**

- **Object → stored in Heap**

## Key Points about Class

1.  A class is a **template for objects**.

2.  It contains **variables and methods**.

3.  It helps implement **OOP concepts**.

4.  Objects are **instances of a class**.

5.  Multiple objects can be created from one class.

---

## Important Points

- A class does not occupy memory until an object is created.

- Objects are instances of a class.

- In Java, everything revolves around classes.

---

## Why We Need Classes?

- To organize code
- To achieve Encapsulation
- To support Abstraction
- To implement Inheritance
- To enable Polymorphism

(These are the 4 pillars of OOP.)

---

## Example with Multiple Objects

    class Student {
        String name;
        int age;
    }

    public class Main {
        public static void main(String[] args) {

            Student s1 = new Student();
            Student s2 = new Student();

            s1.name = "Jay";
            s2.name = "Rahul";

            System.out.println(s1.name);
            System.out.println(s2.name);
        }
    }

Output

    Jay
    Rahul
