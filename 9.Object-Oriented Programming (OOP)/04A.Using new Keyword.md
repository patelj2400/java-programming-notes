# Object Creation in Java Using the `new` Keyword

The **`new` keyword** is the **most common way to create objects in Java**.
It **allocates memory in the heap** and **calls the constructor** of the class.

---

### Syntax

    ClassName referenceVariable = new ClassName();

- **ClassName** → Name of the class

- **referenceVariable** → Reference to access the object

- **new ClassName()** → Creates the object

---

### Example

    class Student {
        String name = "Jay";
    }

    public class Main {
    public static void main(String[] args) {

            Student s1 = new Student();   // object creation using new

            System.out.println(s1.name);
        }
    }

### Output

    Jay

---

## What Happens Internally (Step-by-Step)

When this line runs:

    Student s1 = new Student();

#### 1. Memory Allocation

- JVM allocates memory in **Heap Memory** for the object.

#### 2. Constructor Call

- The **constructor of the class** is executed.

#### 3. Reference Assignment

- The **reference variable (`s1`)** in the **stack** points to the object in the heap.

---

### Memory Representation

    Stack Memory    Heap Memory
    ------------    ----------------
    s1 -----------► Student Object
                    name = "Jay"

---

## Example with Constructor

class Student {

    Student() {\
        System.out.println("Object Created");\
    }

}

public class Main {\
 public static void main(String[] args) {

        Student s1 = new Student();

    }\

}

### Output

Object Created

---

## Creating Multiple Objects

class Car {\
 String model = "Tesla";\
}

public class Main {\
 public static void main(String[] args) {

        Car c1 = new Car();\
        Car c2 = new Car();

        System.out.println(c1.model);\
        System.out.println(c2.model);\
    }\

}

Each `new` creates a **separate object in heap memory**.

---

✅ **Key Points**

- `new` **creates a new object**

- Memory is allocated in the **heap**

- **Constructor is automatically called**

- Returns a **reference to the object**
